MES CONTROL CENTER · CONCEPT REVIEW

启动器与终端管理，可整合为一个控制中心

统一可执行程序保留现有服务启停脚本和终端 HTTP API，只整合入口、状态与交互层。下面三种布局均可采用本地 Web 独立页面展示，也可封装进 WebView2 桌面壳。

结论：可以整合一个 EXE · 两个功能域 · 共用状态与确认机制
服务控制复用 mes-service-control.ps1
终端管理复用现有终端控制 API
页面载体localhost 独立页 / WebView2
业务规则影响不触碰 MQTT 与实验室流程

三个布局方案

点击方案按钮切换完整界面。示例数据用于呈现信息层级，不会执行真实启停或终端命令。

A · 控制台总览推荐

服务与终端权重均衡，日常启动、关闭、查看终端状态都只需一层导航，最适合作为默认首页。

B · 终端工作台高频运维

终端表格获得最大空间，选中即显示权限和远程操作；适合终端数量继续增长后的集中维护。

C · 模块化首页可扩展

用卡片承载服务、在线率、命令和告警，未来增加日志、版本、备份等模块时最灵活。
