# MES 控制中心 v2.7.2

发布日期：2026-10-21。程序文件版本：`2.7.2.0`；桌面工具及升级包中的控制中心版本：`2.7.2`。

## 本次更新

本次优化开发机启动与重启：四项 HTTP 健康检查并行执行，生产前端提前构建并与后端启动重叠；单一物理 IPv4 网关使用 .NET 快速识别，多网卡／VPN 情况沿用原路由选择。控制中心继续统一打开和管理三个网页。通过控制中心启动时，设置 `UPPER_COMPUTER_SIMULATOR_OPEN_BROWSER=false`，避免后端额外打开一个无法跟踪的普通标签页；上位机服务的自动连接和自动模式继续按原流程执行。

- 点击“关闭系统”并成功停止服务后，同步关闭由控制中心打开的 MES、LIMS、上位机模拟器三个网页；重启成功后关闭旧窗口并重新打开页面。
- 使用独立的 Edge/Chrome 配置，普通浏览器窗口不受影响。“关于与访问地址”的“浏览器打开”也纳入管理。
- 保存浏览器进程记录，退出后重新打开控制中心仍能关闭此前的 MES 窗口；适配浏览器启动时更换进程的情况。
- 保留 v2.6 的操作按钮恢复、中心进度弹窗、100% 后自动隐藏，以及 v2.5 的局域网地址和 Docker 启动优化。
- 窗口标题、侧栏、“关于”、文件版本、构建默认名称、部署快捷方式及包清单统一为 v2.7.2。

开发环境及 Docker 的 demo 模式统一打开 MES、LIMS、上位机模拟器三个网页；Docker 的 mes 模式只打开 MES。原生版通过“关于与访问地址”打开的窗口也会在关闭系统时同步关闭。

关闭控制中心右上角的 × 仅退出控制中心。升级前已在普通浏览器中打开的标签页需手动关闭一次；独立浏览器配置首次使用需重新登录。窗口记录和浏览器配置保存在 `%LOCALAPPDATA%\MesFastApiLauncher\Browsers`。

没有 Edge/Chrome 或窗口等待页面确认而未能关闭时，操作结果会提示原因，服务操作按实际执行结果显示。

## 本机实测

同一台电脑优化前后各执行一次完整启动和重启（控制脚本耗时，不含浏览器打开和进度弹窗停留）：

| 项目 | 优化前 | 优化后 | 减少 |
|---|---:|---:|---:|
| 启动系统 | 12.65 秒 | 8.26 秒 | 约 35% |
| 重启系统 | 14.49 秒 | 9.17 秒 | 约 37% |
| 首次网卡识别 | 2.26 秒 | 0.07 秒 | 约 2.19 秒 |

结果仅代表当前开发机的单次对比，不代表 Windows 系统开机、其他 PC 或 Docker／原生服务的启动收益。这三项优化作用于 `start-dev.ps1` 与 `mes-service-control.ps1`；Docker／原生版仍使用各自的服务接口。

前端仍在每次启动构建，保留原子发布、失败重试和旧版本回退；只有构建成功（或已有可用回退产物）且后端就绪才启动前端服务。并行检测仍按原条件检查四项服务，不提前显示成功。项目的 `scripts/MesHttpProbes.cs`、`scripts/MesTcpListeners.cs` 需与控制脚本一同保留。

## 当前开发机使用

退出旧控制中心窗口，双击桌面 **MES控制中心_v2.7.2.exe**。该程序绑定本项目目录，管理 API 8000、Web 5173、LIMS 8900 和上位机 8899。

重新构建：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_control_center.ps1
```

迁移到另一台开发机时，应在目标项目目录重新构建。

## 已部署 Docker／原生版升级

将完整的 `MES控制中心升级_20261021-v2.7.2` 文件夹复制到目标 MES 主机。退出要升级的控制中心窗口，在升级文件夹打开 PowerShell，指定原桌面工具目录：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Update-ControlCenter.ps1 `
  -DesktopToolsDirectory "D:\MES\desktop-tools"
```

脚本读取并保留原 `mes-desktop-tools.json`，自动选择 Docker／原生版，校验文件后备份并替换对应控制中心。Docker 版同时更新控制脚本和 release 中的部署启动脚本。桌面生成 **MES控制中心_v2.7.2_Docker版** 或 **MES控制中心_v2.7.2_原生版** 快捷方式。

备份在原桌面工具目录的 `control-center-backup-日期-时间` 中。复制更新文件不会重启当前业务服务；Docker 启动脚本更新在下次启动或重启系统时应用。该升级包不包含业务镜像或数据库备份，原安装器副本不会自动更新。

构建升级包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_control_center_update.ps1 `
  -OutputDirectory "D:\MES控制中心升级_20261021-v2.7.2"
```

输出目录必须尚不存在。完整桌面工具可继续通过 `scripts/build_desktop_tools.ps1` 构建。
