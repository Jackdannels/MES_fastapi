# 工位客户端 v1.7.0 本机验证

日期：2026-11-08。

## 已交付

桌面 `MES工位客户端_本机测试` 原目录内更新 15 套客户端，保留各自 `mes-client.json`、网页用户数据及下载配置。原中控三合一客户端和控制中心未替换。

- 非中控工位：通过现有固定终端注册和短期票据接口自动认证，不再每次输入登录账号。
- 中控：保留登录及 MES／LIMS／上位机三合一页签。
- 可视化：移除原生单页页签，保留普通最大化窗口。
- 其余 14 个工位：移除单页页签，直接无边框全屏。
- 页面“退出登录”改为“关闭”，与窗口关闭和 Alt+F4 共用一次主题确认；默认取消，取消保持原页面，确认只关闭当前客户端。
- 工位免登录不改变实验间内部员工签到与业务权限。

## 本机绑定

15 个工位已在当前 Windows 用户完成一次绑定。工位密钥经 DPAPI 加密保存在本机客户端数据目录，不在交付文件夹、EXE 配置或进程参数中保存管理员密码。凭据失效、绑定房间不一致、服务器地址变化时停止自动进入并提示重新绑定。

复制到其他电脑、变更 Windows 用户或服务器地址后，需由管理员重新绑定对应工位。本轮未迁移其他电脑或执行实验业务操作。
