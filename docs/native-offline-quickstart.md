# MES 原生离线安装包

版本：2026.10.20-native.1，Windows 11 x64；安装器修订：2026.10.20.2（内置 Docker 数据迁移）。

## 直接使用安装器迁移

将 `MES-Native-Setup-20261020-r1.exe` 复制到已经运行 MES Docker 的新 PC，以管理员身份运行。**导出工具已经整合进 EXE，无需手动执行 PowerShell 或 Python 命令，也无需携带旁边的 payload 文件夹。**

迁移前结束正在进行或暂停的试验，处理完消息队列并暂停新增业务录入。Docker Desktop 在导出阶段需要保持运行。

1. 选择完整主机安装，包含主系统、两个模拟器和三个桌面程序。
2. 程序目录使用默认值，数据目录使用新的空目录，例如 `C:\ProgramData\MESNative`；程序和数据路径须为无空格英文路径。
3. 正式切换选择正常端口。主机本机使用时 MES URL 可留空；局域网使用时填写 `http://主机实际IP:15173`。
4. 设置管理员账号和密码（至少八个字符）；密码留空则自动生成并保存在受限的 `config/native.json`。
5. “业务数据来源”选择“从本机当前 Docker 部署导出并迁移”。
6. 选择旧 Docker release 目录：`C:\Users\Administrator\Desktop\MES_Docker迁移交付_20261019-r1\release-20261019-r1`，或该 PC 实际目录。
7. 检查自动填写的 `.tmp\portable.env`，若旧部署使用其他环境文件则选择实际文件。
8. 选择新的备份目录，默认 `C:\MESBackups\docker-final-日期-时间`。目录及旁边的同名 `.log` 文件必须尚不存在；备份应位于原生程序、原生数据及旧 release 目录之外。
9. 开始安装。安装器自动检查、暂停旧业务、导出并校验数据、停止整个旧 Docker 部署、恢复数据并安装原生 Windows 服务。

旧 Docker 容器、镜像和数据卷均保留。数据导出失败时工具会尝试恢复原来运行的 Docker 服务，不继续安装原生数据库。导出已校验成功但停止旧部署或后续安装失败时，请保留备份并查看同名 `.log` 及安装器日志；旧 Docker 可能仍全部或部分停止，不要直接向已有原生数据目录重复恢复。

安装后默认地址：

- MES：http://127.0.0.1:15173/
- LIMS：http://127.0.0.1:18900/
- 上位机：http://127.0.0.1:18899/

桌面会生成三个“原生版”快捷方式。工作台绑定和终端管理使用本次安装的实际管理员密码。旧 Docker 版快捷方式仍对应旧部署，正式切换后使用新的原生版快捷方式。

确认历史任务、样品、报告、模拟器和桌面程序正常后，退出 Docker Desktop，再检查使用情况；还应在目标 PC 验证断网运行、重启自动启动和局域网访问。验收后再决定卸载 Docker。**原生部署的日常运行不依赖 Docker。**

## 其他安装方式

- 新装空系统：“业务数据来源”选择“新建空数据库”，不需要 Docker。
- 已有导出备份：选择“从已有备份恢复”，选取真实备份目录中的 `data-manifest.json`。
- 同机预演：选择隔离预演端口、独立实例名和空数据目录。Docker 数据导出后会恢复旧服务继续运行，原生 MES 地址为 `http://127.0.0.1:25173`。正式切换时重新导出最新数据。
- 单独导出：完整交付包中的 `payload/native/Export-DockerData.ps1` 提供 PowerShell 入口，具体参数见 `docs/native-offline-deployment.md`。

## 文件夹内容与验证范围

- `MES-Native-Setup-20261020-r1.exe`：完整安装入口，含私有运行环境、迁移工具、主系统、两个模拟器和三个桌面程序。
- `payload/`：用于校验、维护和单独导出的完整运行文件。
- `prerequisites/`：离线 VC 运行库。
- `docs/native-offline-deployment.md`：详细说明。
- `verification/`：本机隔离测试记录及验证范围。
- `migration-rehearsal-backup/`：本机测试快照，**不是新 PC 当前最新数据，请勿用它替代当前 Docker 数据。**

程序运行数据默认保存在 `C:\ProgramData\MESNative`；MySQL 数据目录为 `mysql/`，LIMS SQLite 在 `lims/`，报告在 `reports/`。卸载原生程序保留持久化数据。

交付物已在本机隔离环境验证；干净新 PC、系统重启、其他工作站网络和共享备份目录仍需在现场验收。原生系统开始录入新数据后，旧 Docker 快照不再是最新版本，不能直接切回继续使用。
