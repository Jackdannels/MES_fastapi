# 盐雾中途外观检查后的恢复流程显示

盐雾暂停、外观检测返回及恢复准备都属于同一次原运行。中控托盘详情与实验室可视化共用生产托盘流程模型，不增加“等待恢复实验”流程节点。

- 后端已经使用“等待恢复实验”作为中途外观检测返回后的托盘状态；前端保留识别该值，不按位置误判成普通实验室到达，也不回退为样品运输中。
- 该值不加入人工可选状态列表。恢复准备仍沿用送至盐雾试验室、重新比对、安装、夹具确认及准备就绪。
- 暂停恢复只重置本次盐雾需要重新执行的准备步骤。到货和原暂存历史按该任务、托盘的实际历史/仓储事件显示，不根据模板中的前后顺序自动判为已经过暂存间。
- 有原始记录时保留实际到达状态及时间；只有明确状态记录但无有效时间时不补造时间；没有暂存记录时不把节点标为已达。
- 过滤其他任务、其他托盘、当前暂停以后的记录；多试验中上一个已完成试验之前的暂存记录不用于填充当前盐雾的转运段。
- 多次暂停时使用当前运行的最新暂停上下文，保留此前真实暂存时间；恢复运行后也使用相同历史判断。

回归位于frontend/src/modules/samples/saltSprayResumeHistory.test.js，覆盖无暂存历史、真实历史、仓储事件、缺失时间、多次暂停、多托盘、跨任务和多试验，以及生产组件渲染。
