# 试验数据服务器备份

保留本地 `savePath`，仅将成功生成的 PDF 报告单向备份到服务器。不改变数据库、MQTT、试验控制、原有下载和报告生成流程。

## 配置及启动

### 中控页面设置（推荐）

进入中控“试验数据”→“试验数据备份设置”：

1. 填写 `\\服务器IP\共享名\试验数据`，或在 MES 后端所在 Windows 主机点击“浏览”选择目录。远程浏览器不能控制后端文件选择窗口，请手工填写共享路径。
2. 点击“检测路径与权限”：检测由后端运行账号执行，验证路径格式、可达性、本地/备份目录分离、创建目录、写入、读取校验、文件发布及临时文件清理。检测不改变备份配置，不修改报告。
3. 点击“保存并启用”：重新检测，通过后才原子保存；失败保留原配置。页面同时显示当前生效路径和未保存输入。保存后下一轮备份使用新目录，无需再重启；已经开始的旧目录备份允许完成，旧目录副本保留。
4. “刷新状态”查看当前目标的成功/待处理/失败计数。计数不是实时连通性证明，连接检查须主动点击检测。

检测、保存和浏览接口要求中控登录会话。网络检测在独立子进程运行，最长约 15 秒，两项并发上限；超时结束子进程并返回原因。正常检测仅清理自身创建的临时目录；超时可能遗留 `.mes-backup-probe-*`，仅由管理员在确认检测结束后清理。

页面设置保存在队列文件旁的 `test-data-backup.settings.json`（实际名称随队列文件名变化），优先于 `.env`，每轮读取，重启后保留。配置损坏时暂停备份并报错，不会静默切回其他设备。修改后端启动代码首次上线仍需重启一次。

### 环境变量默认值

Windows 后端主机 `.env`：

```dotenv
TEST_DATA_BACKUP_PATH=\\192.168.110.21\sylu_share\试验数据
TEST_DATA_BACKUP_INTERVAL_SECONDS=30
TEST_DATA_BACKUP_TIMEOUT_SECONDS=120
TEST_DATA_BACKUP_BATCH_SIZE=50
```

UNC 值不要加引号，避免 dotenv 将双反斜杠转义成单反斜杠。目标根目录必须事先存在，运行后端的 Windows 账号必须具有共享和文件系统写权限。不要把 `TEST_DATA_SAVE_PATH` 或界面中的本地保存路径改成这个地址。共享认证使用操作系统已建立的凭据，不在代码中保存共享密码。

修改环境变量默认值后重启 MES 后端；已有页面配置时，修改目标请优先使用页面。每次启动自动发现数据库内已有成功报告，此后约每 30 秒扫描新报告，单批最多 50 项。同步是异步最终一致，不保证本地保存瞬间服务器已有副本。待备份文件必须保留在本机；未上传之前本机磁盘损坏仍可能导致丢失。

默认队列文件为仓库 `.runtime/test-data-backup.sqlite3`，可通过 `TEST_DATA_BACKUP_STATE_PATH` 设置本机绝对路径。不要删除队列或放到网络盘；重启后失败项继续重试。源元数据被清除后，已入队项目仍保留；业务数据库暂时不可达时仍尝试已有队列。尚未被扫描入队的报告依赖数据库导出记录，不能在备份前清除记录。

Docker/Linux 不能直接使用 Windows UNC 地址，需要管理员先挂载 SMB，再将共享挂载目录映射给容器，配置容器内绝对路径。队列使用另一个可写、持久化的本地卷。迁移后端账号、主机或部署方式后，应重新验证共享权限。

## 完整性与保留策略

- 按原有“任务/试验/轴向（如有）/批次/样品.pdf”结构保存。
- 先写唯一临时文件，完成 SHA-256 校验再发布最终文件；重试不会覆盖不同内容的文件。
- 若同名文件内容不同，保存为 `样品.<完整SHA256>.pdf`，保留原版本。
- 本地删除、清空演示数据、修改本地目录均不删除服务器备份。
- 新文件/变更文件优先排队，已备份项目约每小时再次校验。服务器文件缺失时，只要源文件仍在就会补传；检测到不同内容时保留原文件并生成校验正确的版本。
- 网络操作运行于独立子进程，超时后结束该进程并稍后重试，不阻塞 FastAPI 或 MQTT。中途强制退出可能遗留 `.mes-backup-*.tmp`，它们不被视为成功报告；仅在备份进程停止后由管理员清理确认无用的临时文件。

## 状态与验收

`GET /api/test-data/backup-status` 返回是否启用、目标目录、进行中状态、最近进程错误及本地队列计数（`pending` / `synced` / `failed`）和最近 20 个失败原因。此接口不访问共享目录。`synced` 表示最近一次校验通过，不代表远端此刻必然在线；进程正常退出不表示所有文件成功，必须同时检查 `counts.failed`。

管理员也可在项目目录手动运行一轮：

```powershell
python -m app.services.test_data_backup
```

验收：生成报告后对比本地和服务器 SHA-256；中断共享连接时确认本地试验及报告功能正常、队列失败可见；恢复连接并重启后端，确认补传成功；删除本地已备份文件后确认远端仍保留。

若需停用：管理员可先停止后端，再将页面配置文件中的 `backupPath` 设为空（如果存在），同时将 `TEST_DATA_BACKUP_PATH` 设为空，然后启动后端；不会删除任何副本。页面目前只提供目录检测与保存启用，不提供删除副本功能。
