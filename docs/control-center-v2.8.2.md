# MES 控制中心 v2.8.2

## 关闭控制中心时同步关闭系统

点击控制中心右上角“×”或按 Alt+F4，会先显示“关闭系统并退出控制中心”确认框，默认选中“取消”。

- 取消：保留控制中心与当前系统状态。
- 关闭并退出：执行一次关闭系统，停止部署对应的 MES 后端、前端及模拟器服务，再关闭托管的中控和模拟器界面；全部成功后退出控制中心。
- 服务或界面关闭失败：显示失败原因并保留控制中心，处理后可重试。
- 界面打开或服务操作进行中：等待操作完成后才能关闭。

窗口不提供“只退出控制中心”选项。需要保留服务时可最小化控制中心。停止服务会中断系统连接，请在确认框中确认后执行。业务数据库、报告和文件按既有关闭脚本保留。

## 配套中控客户端 v1.5.1

中控界面的退出提示随当前页面主题切换：浅色使用白色与蓝色，深色使用深灰与薄荷绿；说明文字和按钮保持清晰对比。默认聚焦“取消”，Enter 和 Esc 都取消退出。

单独关闭中控界面仍只关闭界面，后台服务与控制中心保留，可通过“打开中控管理”重新进入。控制中心已确认的关闭操作直接关闭关联界面，不再重复询问。

## 原目录更新

保留 `mes-desktop-tools.json` 与 `central-client/mes-client.json`。更新工具继续校验文件并保存回退文件。控制中心必须退出后才能替换 EXE；从 v2.8.2 开始，正常退出控制中心会同步关闭系统，应安排在允许停机时更新。

本轮使用临时控制脚本、临时客户端与真实 WebView2 进行本机隔离验证，没有为测试关闭当前业务服务。
