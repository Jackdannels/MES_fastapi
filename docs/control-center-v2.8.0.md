# MES 控制中心 v2.8.0

日期：2026-11-07。

## 本次迭代

- 程序文件、程序集、标题、侧栏品牌及“关于”页面统一升级至 v2.8.0。
- 配套中控界面／客户端 v1.4.0，支持同一窗口中的中控、LIMS、上位机入口。
- 专用客户端入口、单实例唤起和等待实际退出保持统一；缺少客户端时保留旧浏览器入口。
- 客户端顶部导航跟随当前页面主题，底部不再显示常驻说明；左侧显示界面版本和本机局域网 IPv4。
- 升级过程保留原有服务地址、配置及业务数据。本机控制中心关闭按钮只退出管理窗口；“关闭系统”才调用已有服务控制脚本。

## 本机更新

当前已解压目录继续使用原路径，更新前备份旧程序，保留 `mes-client.json` 与 `mes-desktop-tools.json`。中控界面需要对应前端代码；本机开发服务会读取当前项目代码，静态前端环境通过既有发布流程使用新构建。

## 验收范围

本机验证程序元数据与界面版本、三合一入口、生命周期、主题同步和配置保留。测试服务与模拟器数据隔离，未执行真实停服、数据库迁移或其他电脑部署。
