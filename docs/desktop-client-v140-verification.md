# 中控界面 v1.4.0 与控制中心 v2.8.0

日期：2026-11-07。

## 变更

1. 原生顶部导航监听当前页面的主题属性变化，浅色使用蓝白配色，深色使用原深色配色。
2. 移除底部常驻说明和正常状态下的占位；临时下载提示自动隐藏。
3. 中控左侧“自动采集／固定报告”下方显示版本及本机局域网 IPv4。优先列出带网关的物理有线／Wi‑Fi 地址，排除回环、链路本地和常见虚拟网卡。每 30 秒通过只读本机桥接刷新。
4. 普通浏览器没有原生网卡信息时，明确显示服务地址，不把服务器地址误标为本机网卡地址。
5. 控制中心文件版本、程序集版本、标题、品牌与关于页面统一为 v2.8.0，构建、更新脚本和校验同步。

## 验证

- 前端侧栏信息、桥接刷新及释放、App 和主题定向测试。
- 编译后客户端的主题变化、正常页底部隐藏、只读主机信息桥接、生命周期和三合一回归。
- 控制中心构建、程序集／文件版本、关于页面、升级包和配置保留回归。
- 前端 lint、生产构建和本机静态服务所返回资源一致性。

本机 5173 使用当前项目 `frontend/dist` 的静态服务，构建后直接提供新资源；更新不停止后端、模拟器或数据库。客户端与控制中心在已解压目录中备份迭代，保留地址配置。
