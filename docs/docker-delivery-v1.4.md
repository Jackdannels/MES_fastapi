# 5826信息化交付v1.4

双击 `5826信息化交付v1.4_安装程序.exe`。选择自定义安装路径、当前网卡及所需工位，自动解压、导入镜像、恢复数据、启动并验证服务。支持中文和空格路径。

主机需要已初始化的 Docker Desktop Linux 引擎。包内含 WebView2 离线运行库，已安装时跳过。目标机无需开发环境、Python、Node 或 C# 编译器。

## 桌面与安装目录

主机安装完成后，桌面只生成 `MES控制中心.exe` 和 `MES中控管理.exe` 两个真实 EXE 启动入口。它们定位安装目录中的程序，不能代替整个客户端文件夹分发到其他电脑。中控管理可以独立打开；服务需先启动。

```text
自定义安装目录/
├─ MES控制中心.exe
├─ 中控管理/
├─ 工位终端/                 仅生成所选工位
├─ 卸载5826信息化系统.exe
├─ 安装记录.json
├─ 使用说明.md
└─ .mes/                     隐藏内部资源、部署配置、日志及补全库
```

不再生成独立的终端管理、工作台设置或通用接入目录；正式包不包含综合测试终端。工位安装不生成额外桌面快捷方式，从各工位文件夹打开程序。每个工位包含 `MES终端接入.exe`，默认固定对应工位，经控制中心批准后进入。

## 安装进度

安装界面覆盖环境检查、解压校验、镜像导入、数据恢复、服务启动和最终验证。执行中显示当前阶段及已用时间；只有收到最终成功结果才显示100%。相同镜像自动复用，已完成的数据恢复不重复执行。

首次镜像导入、数据库恢复和服务启动仍需要时间。日志位于 `.mes/logs/install-progress.log`，最新失败原因在 `last-install-error.txt`。若恢复数据中断，保护机制会拒绝直接覆盖部分数据。

首次安装生成独立登录凭据，可在安装目录 `.mes/connection-info.txt` 查看。该文件和环境配置只供安装用户及管理员访问。

## 卸载与重复安装

运行安装目录中的 `卸载5826信息化系统.exe`，或在安装程序欢迎页选择“卸载已有安装”。确认安装路径后选择：

- **卸载程序，保留业务数据**：停止并移除本安装的容器和网络，删除程序及桌面入口；保留数据卷和受保护的 `.mes/retained` 记录。同版本在原目录重装时，使用原凭据及业务数据，不导入交付初始快照。
- **彻底卸载并清空业务数据**：再次确认后删除本安装的数据卷、程序和配置，释放服务端口，可在同目录、同端口全新安装。

卸载按独立安装ID和安装记录核对容器、卷、网络与桌面入口。其他 Docker 项目、Docker Desktop 和共享镜像保留。目录中的用户额外根文件不会自动删除。工位电脑卸载只清理本机客户端。

卸载记录保存在当前用户 `%LOCALAPPDATA%/Mes5826Uninstall`。如果端口仍被其他进程占用，会列出端口，需要处理实际占用程序。部分恢复的数据不能自动作为完整业务库复用。

## 控制中心与补全

控制中心保留深浅主题、终端申请审批、重置、中文系统配置和“系统完整性”。可检测缺失文件并按组件补全，现有配置及绑定保留。离线库包含全部可选工位，未选装工位可以后续补装。

控制中心使用蓝色图标；客户端使用逐显示器DPI适配，页面缩放100%。复制工位时保留整个文件夹及 EXE.config。

实验准备、开始、结束继续使用 MQTT；高低温湿热二室本地装样及夹具就绪例外保持原业务规则。
