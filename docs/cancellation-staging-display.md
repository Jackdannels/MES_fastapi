# 取消后可选暂存节点的显示规则

“送至暂存间”和“已到达暂存间”为可选过程节点。`reached` 表示流程已越过该阶段，不等同于发生了实际入库。

| 情况 | reached | inferred | 时间 | 显示 |
|---|---|---|---|---|
| 刚取消、等待后续去向或霉菌恢复中 | false | false | 空 | 灰色 |
| 已进入取消后的下一实验室流程，无暂存操作记录 | true | true | 空 | 绿色 |
| 有实际暂存操作记录，已经离开该阶段 | true | false | 实际操作时间 | 绿色 |
| 当前正在执行相应暂存步骤 | 依原实际状态 | false | 有记录则显示真实时间 | 当前蓝色高亮 |

只有本托盘在本次取消之后发生的实验室派送、比对、安装、就绪、运行等证据可以触发推导；排程本身、旧运行和其他托盘记录不触发。新的取消开始新的推导周期。

只有到达暂存间记录而没有派送记录时，派送节点可推导为已越过，但时间仍为空，不能挪用到达时间。

样品页和可视化统一使用绿色推导节点，可提示“推导节点，暂无实际时间记录”。当前高亮与待执行灰色不变。

本规则只作用于前端展示，不写入业务状态、库位或出入库日志，不改变霉菌取消恢复要求、盐雾专用流程和设备接口边界。

## 霉菌取消后的下一轮准备流程

取消/恢复处理期间，旧运行的准备节点折叠为取消历史，但下一轮仍展示一套全新的“送至实验室 → 到达/任务比对 → 工装夹具安装 → 实验准备就绪”。这些预测节点均为灰色、无实际时间，不表示允许跳过业务操作。

- 无有效新排程时，增加“待重新排程”，不猜测目标试验间。
- 有新排程时，按本托盘的排程时间和排程编号选择下一项，排除已取消的旧排程、已完成项目和其他托盘的专属排程。下一项可以是重做霉菌，也可以是其他试验；霉菌义务仍保留未完成。
- 开始实际操作后，准备时间只取本次取消之后、对应目标试验/排程/托盘的操作证据。撤回后的失效记录不能用于后续准备；没有新派送证据的原地重做不生成一次虚假的派送。
- 恢复处理和暂存间沿用现有路径规则，不因新增预测节点而变成强制步骤；排程本身不推进实际状态。
- 样品/托盘页与可视化大屏通过共享 `buildTrayFlowView` 同步展示，不修改持久化数据、MQTT 或本地夹具模拟边界。
