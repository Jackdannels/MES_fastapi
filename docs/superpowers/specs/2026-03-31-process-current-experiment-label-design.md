# 过程管控当前实验标签口径设计

## 目标

修正试验过程管控页中两个位置的实验名称口径：

- 实验室卡片中的“目标实验”
- 点击“查看任务”后详情弹窗中的“试验类型”

当前两处都默认显示任务级 `test_type`，因此会把同一任务下的全部实验类型一起展示。目标行为是只显示当前实验室这条排程对应的那个实验名称。

## 当前问题

过程管控卡片通过实验室找到一条当前/最近排程，但展示时：

- 卡片 `targetExperiment` 使用 `task.test_type`
- 详情 `testType` 也使用 `task.test_type`

这会在多实验任务下显示成：

- `温度冲击试验 / 高低温湿热试验 / 盐雾试验`

而不是当前排程真正对应的那个实验。

## 目标行为

当某实验室存在一条排程记录时：

- 卡片“目标实验”优先显示该 `schedule.experiment_code` 对应的实验名
- 详情“试验类型”优先显示同一实验名

例如当前排程是 `SYLU-2026-03-001-A`，且其实验名为 `高低温湿热试验`，那么：

- 卡片只显示 `高低温湿热试验`
- 详情也只显示 `高低温湿热试验`

## 回退规则

为了兼容旧数据，按以下顺序回退：

1. 当前排程 `experiment_code` 对应的实验名
2. 任务级 `test_type`
3. 实验室默认 `testType`
4. `-`

## 实现边界

本次只修改：

- `frontend/src/modules/process/model.js`
- `frontend/src/modules/process/useProcessLabs.js`
- 对应测试

不改托盘口径、排程逻辑、接驳区或样品页。

## 验证要求

新增或更新测试覆盖：

- 卡片在多实验任务下只显示当前排程实验名
- 详情“试验类型”也只显示当前排程实验名
- 当缺少 `experiment_code` 或找不到实验记录时，仍按既有回退规则显示
