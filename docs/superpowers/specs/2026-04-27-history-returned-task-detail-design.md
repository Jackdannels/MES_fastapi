# 历史任务数据与预接驳去重设计

## 背景

`样品预接驳` 已成为独立导航入口后，页面和 `样品/托盘信息` 里仍存在重复的预分装说明与入口。`历史任务数据` 当前只是任务表格，没有按“厂家收回任务”查看托盘和流转时间。

## 目标

1. `样品预接驳` 页面删除顶部重复的 `样品预分装`、`总任务清单` 与下方说明文本。
2. `样品/托盘信息` 删除顶部嵌入的样品预分装卡片，只保留样品流转、暂存间、托盘信息能力。
3. `历史任务数据` 仅展示所有托盘均为 `厂家收回` 的任务。
4. 点击历史任务后，右侧按 A 方案展示：
   - 任务流转信息及时间。
   - 当前任务分配的托盘。
   - 选中托盘的流程节点及每个节点对应时间。

## 方案

- `TransferWorkbench` 在 `pre-allocation` 模式下隐藏 overview 页标题和说明块，只保留筛选、任务列表和分页。
- `SamplesManagementPanel.vue` 移除 `TransferWorkbench embedded mode="pre-allocation"`，避免和独立导航重复。
- 新增 `frontend/src/modules/task-history/model.js`：
  - 从任务、样品快照中筛选所有托盘状态均为 `厂家收回` 的任务。
  - 汇总每个任务的托盘编号、样品编号和最新时间。
  - 从样品 `history` 中提取任务级流转时间和托盘流程节点时间。
- `task-history/page.vue` 使用左任务列表 + 右详情布局。默认选中第一条历史任务，点击任务切换详情，点击托盘切换流程时间。

## 验证

- 预接驳页不再出现 `样品预分装`、`总任务清单` 和原说明文本。
- 样品/托盘信息不再加载预接驳工作台。
- 历史任务只包含全部托盘厂家收回的任务。
- 历史任务详情展示任务流转时间、托盘列表和选中托盘每个流程节点时间。
