# 任务重置与单一实验类型展示 Design

**背景**

当前系统存在两类口径混杂的问题：

1. 演示任务数据允许一个任务的 `test_type` 直接保存为多实验类型组合串，且重置后仍可能出现重复实验类型。
2. 排程看板和任务受理页的“实验类型”下拉直接消费组合串，导致下拉项出现：
   - `冲击试验 / 霉菌试验 / 温度冲击试验`
   - `盐雾试验 / 盐雾试验 / 高低温湿热试验`
   这种不适合作为筛选条件的组合项或重复项。

目标是同时清理数据和统一界面口径。

---

## 目标

1. 将当前任务全量重置到初始前置态。
2. 重建后的任务必须满足：
   - 每个任务允许多个实验
   - 同一任务内实验类型不允许重复
3. 排程看板的手动排程区域不再用实验编号列表做主筛选，而改成单一实验类型列表。
4. 任务受理页的实验类型筛选也改成单一实验类型列表，并按“包含该实验类型”进行匹配。

---

## 数据口径

### 任务重置

继续沿用现有 demo reset 的初始状态：

- 任务状态：`待排程`
- 样品状态：`运输中`
- 清空：
  - `mes.schedules`
  - `mes.experiment_trays`
  - `mes.experiment_samples`
  - `mes.streams`
  - `mes.conflicts`

### 任务实验生成规则

重建任务时：

- 每个任务仍生成 3 个实验
- 3 个实验类型必须互不重复
- `task.test_type` 继续保存为展示串，但必须由去重后的实验类型拼接得到
- `task.required_device` 保持为第一个实验类型，沿用现有字段习惯

示例：

- 合法：`冲击试验 / 盐雾试验 / 高低温湿热试验`
- 非法：`冲击试验 / 冲击试验 / 盐雾试验`

非法情况不做原地修补，而是在重置时直接重新生成任务实验组合。

---

## 排程看板

### 现状问题

手动排程表单当前使用具体实验记录构建选项，导致“实验类型”列表出现重复和组合串混入。

### 新规则

- 手动排程中的“实验编号”选择口径改成“实验类型”
- 下拉项来源为全局实验记录的 `experiment_name`
- 对下拉项做：
  - 去空
  - 去重
  - 中文排序
- 下拉里只保留原子实验类型，例如：
  - `冲击试验`
  - `盐雾试验`
  - `高低温湿热试验`

**注意**

这只是表单展示和选择口径的变化，不改变底层具体实验记录。真正提交排程时仍要能映射回任务下对应的具体实验。

---

## 任务受理

### 现状问题

任务受理页的实验类型筛选项当前直接取 `row.testType`，因此会把组合串作为 option 渲染出来。

### 新规则

- “全部实验类型”下拉只显示单一实验类型
- 下拉项来源为任务行的实验类型集合拆分后去重
- 选择某个实验类型时，筛选规则改成“包含匹配”

示例：

- 任务 A：`冲击试验 / 盐雾试验 / 霉菌试验`
- 任务 B：`高低温湿热试验 / 冲击试验 / 四综合试验`
- 选择 `冲击试验` 时，A 和 B 都要显示

这不是“完全等于”匹配。

---

## 实现边界

### 需要改

- demo reset 生成逻辑
- 排程看板实验类型 option 的构建逻辑
- 任务受理页实验类型 option 的构建和筛选逻辑
- 相应前端/后端测试

### 不需要改

- 多实验任务本身的存在方式
- 每个任务最多 3 个实验的结构
- 已有实验实体的持久化结构
- 手动排程最终写入的具体实验记录格式

---

## 测试策略

### 后端

- demo reset 后任务数量、实验数量、样品数量保持预期
- 所有任务的实验类型集合不重复
- `task.test_type` 与对应实验集合一致

### 前端

- 排程看板实验类型下拉只显示单一实验类型且无重复
- 任务受理页实验类型下拉只显示单一实验类型且无重复
- 选择 `冲击试验` 时，能筛出所有包含 `冲击试验` 的任务

---

## 风险与处理

### 风险 1：排程看板表单从“实验编号”切到“实验类型”后，提交时找不到具体实验

处理：

- 保留内部具体实验记录，只改变 option 的展示与选择来源
- 若同一任务下存在多个同名实验，这在新重置规则下不会再发生

### 风险 2：旧任务数据仍残留组合串

处理：

- 这次直接执行全量重置和重生
- 不再保留不符合规则的旧任务组合

### 风险 3：任务受理筛选与其他页面口径不一致

处理：

- 提取统一的实验类型拆分/去重辅助逻辑
- 排程看板与任务受理共用同一组“原子实验类型”口径
