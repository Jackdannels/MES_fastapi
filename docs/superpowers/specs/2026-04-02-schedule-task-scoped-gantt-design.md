# 排程看板任务范围甘特图设计

## 背景

当前排程看板已经支持任务、实验、实验室和时间段排程，也能在甘特图中看到正式实验室的上午/下午占用情况。但页面仍有三个明显缺口：

1. 选择任务后，甘特图仍按全部实验室或当前实验室展示，无法收敛到该任务真实涉及的实验室集合。
2. 同一任务在不同实验室中的排程块没有稳定的任务级颜色，跨实验查看时识别成本高。
3. 甘特图把同一个上午/下午单元格内的多条排程直接视为冲突，无法表达“时间不重叠但落在同一半天”的合法并存排程。

## 目标

本轮只增强排程看板的展示逻辑，不改变排程创建、编辑、删除和冲突校验的落库规则：

1. 选择任务编号后，甘特图只显示该任务关联到的实验室行。
2. 同一任务在任意实验、任意实验室中的排程块保持同一主色。
3. 同一个上午/下午单元格内允许展示多个互不重叠的任务，其中最多显式展示 2 个任务编号，超过部分用 `+N` 表示。
4. 单元格尺寸保持不变，只允许通过字号、行高和内部布局压缩来承载多任务显示。

## 业务规则

### 任务筛选后的实验室范围

- 任务选中后，甘特图的设备行不再只依赖当前表单中的 `device`。
- 系统需要根据该任务汇总“应显示的实验室集合”：
  - 来自该任务下所有实验记录的 `required_device`
  - 来自该任务已存在正式排程记录的 `device`
- 某个实验如果可以对应多个实验室，这些实验室都保留。
- 暂存间不进入该集合。
- 未选择任务时，甘特图保持现有全局视图。

### 任务级颜色

- 颜色基于 `task_code` 稳定映射，而不是基于实验室或状态。
- 相同 `task_code` 在所有设备行里使用同一主色。
- 运行中、已完成等状态继续保留，但只通过同色的明暗、透明度或边框变化表达，不改变任务主色归属。
- 空闲单元格继续使用现有灰色体系。

### 同半天单元格的多任务显示

- 甘特图上午/下午单元格的归类维持现有半天模型。
- 同一个半天单元格内，如果有多条正式排程命中：
  - 先按真实开始时间排序
  - 如果这些排程彼此时间不重叠，则视为“可并存显示”
  - 如果存在真实时间重叠，则仍视为冲突状态
- 可并存显示规则：
  - 1 条排程：单行显示任务编号
  - 2 条排程：双行显示两个任务编号
  - 3 条及以上：显示前 2 个任务编号，底部显示 `+N`
- 单元格高度、表格列宽、整表尺寸不允许改变。

### 冲突与拥挤的区分

- 真实时间重叠：继续使用冲突态样式
- 同半天内时间不重叠但数量超过 1：使用多任务态样式，不归入冲突列表
- 因此“多任务显示”是合法排程展示，不参与原有冲突校验逻辑

## 数据与视图模型

### 甘特图输入补充

排程页视图模型需要新增当前选中任务上下文：

- `selectedTaskCode`
  - 用于收敛设备行范围
  - 用于在 `buildGanttRows` 内推导任务相关实验室

### 甘特图单元格输出补充

现有甘特图段数据以单条 `label` 为主，需要改成支持“单元格内多个任务项”的输出：

- `slotItems`
  - 每项包含 `taskCode`、`scheduleId`、`taskColor`、`state`
- `overflowCount`
  - 超出前两条后的剩余数量
- `displayMode`
  - `idle` / `single` / `stacked` / `conflict`

当一整段连续区域只属于同一个任务且状态一致时，仍允许沿用 `colspan` 折叠，避免回退成逐格渲染。
当单元格存在多任务并存或冲突时，该格不再和相邻格折叠。

## 页面设计

### 甘特图区

- 未选任务：维持当前整体设备看板视角
- 已选任务：
  - 只渲染该任务涉及到的实验室行
  - 同一任务块在不同实验室使用同色
  - 同半天多任务时，单元格内部垂直堆叠显示

### 单元格样式

- 单元格按钮维持现有外轮廓，不改变高度
- 多任务态使用纵向布局：
  - 文本字号小于单任务态
  - 每行固定高度
  - `+N` 使用弱化标签
- 冲突态继续保留红色风险样式，但要和“合法双行堆叠”区分开

## 代码边界

### `frontend/src/modules/schedule/useSchedulePage.js`

- 把当前任务编号透传给甘特图构建函数

### `frontend/src/modules/schedule/model.js`

- 新增任务级颜色计算
- 新增任务相关实验室集合推导
- 重写甘特图单元格聚合逻辑，支持：
  - 合法多任务并存
  - 冲突和并存区分
  - 任务颜色输出

### `frontend/src/modules/schedule/page.vue`

- 将原先单 `label` 渲染改为单元格内部任务列表渲染
- 支持 `+N` 溢出提示

### `frontend/src/modules/schedule/styles.css`

- 增加多任务堆叠样式
- 增加任务色变量注入样式
- 保持现有表格尺寸和移动端收缩行为

## 测试范围

### 视图模型测试

1. 选中任务后，只保留该任务涉及到的实验室行。
2. 同一任务在不同实验室单元格中输出相同任务色。
3. 同半天内两个不重叠任务会输出双行展示，而不是冲突态。
4. 同半天内三个及以上不重叠任务会显示前两条并带 `+N`。
5. 同半天内真实时间重叠时仍输出冲突态。

### 组合式逻辑测试

1. 任务选择变化时，甘特图过滤上下文跟随任务编号变化。
2. 已选择任务但未选实验室时，甘特图仍按任务实验室范围渲染。

### 页面运行时测试

1. 选择多实验任务后，甘特图只显示对应实验室行。
2. 同一任务在多实验室的任务块样式颜色一致。
3. 同一单元格内两条合法排程以双行显示。
4. 三条及以上时出现 `+N`，且表格列宽、单元格尺寸不扩张。

## 成功标准

1. 排程员选择任务后，甘特图聚焦到该任务真实涉及的实验室。
2. 同一任务在跨实验、跨实验室场景下可以凭颜色快速识别。
3. 合法的同半天多任务排程可以在固定单元格内清晰显示。
4. 真实冲突仍保持风险可见，不与合法并存展示混淆。
