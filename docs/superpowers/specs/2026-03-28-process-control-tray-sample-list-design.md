# 过程管控抽屉托盘样品列表设计

## 背景

试验过程管控任务抽屉当前左侧“执行摘要”同时展示托盘编号和样品编号，右侧仍保留“补充信息”。用户希望把交互收敛为“左侧选托盘，右侧看该托盘样品编号”，避免信息重复。

## 目标

- 删除右侧“补充信息”卡。
- 右侧原位置改为“样品编号”卡，显示当前选中托盘的样品编号。
- 左侧执行摘要只负责托盘维度信息。
- 点击左侧托盘编号时，右侧样品编号列表同步切换。

## 交互定义

- 左侧“托盘摘要”继续显示托盘编号汇总文本。
- 左侧“当前托盘”卡仅显示：
  - 当前托盘编号
  - 当前托盘状态
- 左侧托盘按钮区只显示托盘编号，不再承载样品信息。
- 右侧卡片标题从“补充信息”改为“样品编号”。
- 右侧列表来源于当前选中托盘的 `sampleCodes`。
- 每个样品编号单独占一行。
- 如果当前托盘没有样品编号，则显示空态文案。

## 实现边界

- 只修改过程管控前端抽屉展示。
- 不改后端接口，不改样品/托盘状态逻辑。
- 复用现有 `selectedTrayCode` / `selectedTraySummary` 切换逻辑。

## 测试点

- 抽屉不再渲染“补充信息”。
- 抽屉渲染“样品编号”卡。
- 左侧当前托盘卡不再显示样品编号列表。
- 右侧按每行一个样品编号展示当前托盘样品。
- 点击托盘标签后，右侧样品编号列表跟随切换。
