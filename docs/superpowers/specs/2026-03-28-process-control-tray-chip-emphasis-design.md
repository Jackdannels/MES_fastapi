# 过程管控抽屉托盘编号强化设计

## 背景

当前过程管控抽屉左侧“执行摘要”仍保留一块“托盘摘要”文本，用户更希望直接把托盘编号作为主交互入口，减少重复信息，并让托盘编号更醒目。

## 目标

- 删除左侧“托盘摘要”文本块。
- 左侧执行摘要只保留：
  - 样品数量
  - 托盘数量
  - 可点击的托盘编号按钮组
- 托盘编号按钮整体放大，成为更强的视觉焦点。
- 选中托盘继续驱动右侧样品编号列表和流程图。

## 交互定义

- 不再显示 `托盘摘要` 标题和拼接字符串。
- 若存在托盘编号，直接在统计块下展示托盘编号按钮列表。
- 托盘编号按钮默认尺寸增大：
  - 更高的内边距
  - 更大的字号
  - 更粗的字重
- 选中态保持明显高亮，未选中态也需要足够醒目。
- 右侧“样品编号”列表逻辑不变，仍跟随当前选中托盘。

## 实现边界

- 仅修改过程管控抽屉的页面结构和样式。
- 不改数据结构，不改状态流转逻辑。

## 测试点

- 抽屉不再渲染“托盘摘要”。
- 左侧仍显示托盘编号按钮组。
- 托盘按钮具备更大的样式类或尺寸特征。
- 点击托盘按钮后，现有切换行为不回归。
