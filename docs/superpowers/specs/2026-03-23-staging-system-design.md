# 暂存间系统独立接入设计

## 背景

现有前端已经具备独立模块选择能力，登录页可在中控管理、接驳区系统、可视化管理、暂存间管理之间切换。当前 `staging` 模块仅有占位页，未承载实际业务界面。

用户提供了一套独立的暂存间界面压缩包 `zancun.zip`，目标是将其接入现有系统，使其像中控管理、接驳区系统一样可以在登录界面选择并独立进入。

## 目标

- 保留现有登录和鉴权协议，不新增后端登录枚举。
- 将 `zancun.zip` 内的暂存间界面替换现有 `staging-management` 占位页。
- 在前台文案上将该模块统一展示为“暂存间系统”。
- 登录后进入独立模块外壳，而不是中控导航壳。
- 为导入的暂存间页面补齐模块级测试，覆盖模型逻辑、页面运行时交互、登录文案和壳层接线。

## 非目标

- 不改动后端登录 API 结构。
- 不新增新的模块键，例如 `zancun`。
- 不将暂存间系统并入中控左侧导航体系。
- 不把暂存间页面与现有样品/任务数据做真实后端联通，本次仅接入现有前端静态交互实现。

## 方案选择

### 方案 A：新建 `zancun` 模块

为压缩包创建新的模块键、路由和登录选项，例如 `zancun` / `/zancun`。

优点：

- 命名与压缩包一致。
- 后续若需同时保留旧的 `staging` 模块，兼容性更高。

缺点：

- 需要扩展登录选项、模块路由映射、权限判断与相关测试。
- 纯接线成本增加，但没有带来额外业务价值。

### 方案 B：复用现有 `staging` 模块

保留模块键 `staging` 和路由 `/staging-management`，仅替换模块内容，并统一对外文案为“暂存间系统”。

优点：

- 复用现有鉴权、登录与路由映射，风险最低。
- 改动范围可控，重点集中在前端模块内部。
- 符合“可独立选择、独立进入”的需求。

缺点：

- 内部模块键与外部展示名不完全一致，但这不会影响用户体验。

### 结论

采用方案 B。保留 `staging` 作为系统内部模块标识，对外统一展示为“暂存间系统”。

## 架构与接入方式

### 模块身份

- `frontend/src/auth.js` 继续保留 `staging` 登录值，首页映射继续指向 `/staging-management`。
- `frontend/src/modules/staging-management/index.js` 继续作为模块入口文件。
- 模块元数据中的 `meta.module` 保持为 `staging`，确保与鉴权判断一致。

### 页面外壳

- 暂存间系统使用现有“独立模块”公共外壳，不进入中控中心壳。
- 页面继续挂载在公共壳的页头区域，以保留统一的退出登录操作。
- 导入界面中的 Teleport 行为将继续复用公共壳中的 `.header-actions` 区域。

### 文件落位

将 `zancun.zip` 中的前端文件迁入现有模块目录 `frontend/src/modules/staging-management/`：

- `page.vue`
- `model.js`
- `model.test.js`
- `page.runtime.test.js`
- `styles.css`

压缩包中的 `index.js` 不直接使用，其职责并入现有 `staging-management/index.js`。

## 文案策略

- 登录页入口文案改为“暂存间系统”。
- 模块标签映射中的 `staging` 改为“暂存间系统”。
- 路由标题与副标题统一使用暂存间系统相关表述。

## 数据与行为

- 暂存间系统页面先使用压缩包中自带的前端静态模型与交互逻辑。
- 页面支持：
  - 指标卡展示
  - 样品信息总览弹窗
  - 入库扫码流程
  - 出库扫码流程
- 当前行为为前端内存态更新，不写入后端。

## 错误处理

- 扫码未输入编号时，在弹窗内显示前端警告文案。
- 出库时若编号不存在，返回模型层错误并保持当前数据不变。
- 确认动作仅在无错误结果时更新页面数据。

## 测试策略

需要覆盖以下层级：

- 模型单测：
  - 指标统计
  - 过滤、排序、分页
  - 扫码详情构建
  - 入库/出库状态变更
- 页面运行时测试：
  - 页头按钮 Teleport
  - 总览弹窗打开、筛选、分页、排序
  - 入库扫码流转
  - 出库扫码流转
- 系统接线测试：
  - 登录页存在“暂存间系统”文案
  - `staging` 首页映射保持为 `/staging-management`
  - `staging` 模块鉴权跳转仍然正确
  - `App.vue` 在 `staging` 路由下使用独立模块外壳而非中控壳

## 验收标准

- 登录页可选择“暂存间系统”。
- 使用 `staging` 登录后进入 `/staging-management`。
- 暂存间系统页面展示为独立模块页面，不出现中控中心侧边导航。
- 页面内扫码入库、扫码出库、查看样品信息清单均可按压缩包预期运行。
- 相关前端测试通过。
