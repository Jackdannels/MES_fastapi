# 第四号可视化屏幕当前任务矩阵设计

## 目标

第四号可视化屏幕采用“试验间状态矩阵”方案，显示每个试验间当前选择的任务，并与各试验间系统中的当前任务和状态保持一致。

## 状态口径

- 状态来源复用现有实验室工作台模型和设备状态模型，避免 REST/API 与 MQTT 路径各自维护业务规则。
- 红色：系统记录为故障、维修、维护、校准、保养、停用等不可操作状态。
- 绿色：系统推导为工作中，或实验室工作台存在正在运行的实验。
- 橙色：正在运行且距离计划完成小于等于 30 分钟，或系统记录该试验已完成。
- 蓝色：存在当前任务，但未进入运行、维修或完成状态。

## UI

- 第四屏替换原“样品与托盘统计屏”占位内容。
- 使用 4 列矩阵显示当前所有实验间，暂存间、外观检测间、接驳间不进入该屏。
- 每个试验间卡片显示试验间名称、当前状态、当前任务、试验项目、托盘/样品、阶段和计划完成时间。
- 下方倒计时进度条只出现在正在运行的试验间；非工作中试验间不显示进度条。
- 橙色状态卡片带轻微闪烁，提醒临近完成或已完成。

## 测试

- 覆盖第四屏模型复用实验室当前任务，保证与试验间系统一致。
- 覆盖维修/保养状态优先显示红色。
- 覆盖运行实验显示倒计时进度条。
- 覆盖非工作中试验间不显示倒计时进度条。
- 覆盖临近 30 分钟或已完成显示橙色。
