# 过程管控抽屉托盘编号单列自适应设计

## 背景

过程管控抽屉左侧当前已经只保留托盘编号按钮。用户希望这些托盘编号始终每行一个，同时在托盘数量增多时自动缩小按钮尺寸，避免把执行摘要区域拉宽或拉长到失衡。

## 目标

- 托盘编号按钮始终单列排列。
- 任意托盘数量下都不撑宽执行摘要卡片。
- 托盘数量增多时，按钮自动切换为更紧凑的尺寸方案。

## 交互定义

- `1` 个托盘：使用较大的主按钮样式。
- `2` 个及以上托盘：仍然每行一个托盘。
- 当托盘数量达到密集阈值时，按钮缩小：
  - 字号减小
  - 内边距减小
  - 最小高度减小
- 选中态高亮逻辑不变。
- 右侧样品编号列表和流程图切换逻辑不变。

## 实现边界

- 只改过程管控页面样式和模板类名。
- 不改数据结构和托盘选择行为。

## 测试点

- 托盘按钮列表为单列容器。
- 多托盘场景下容器带有密集布局标记。
- 托盘按钮仍可点击并保持选中态。
