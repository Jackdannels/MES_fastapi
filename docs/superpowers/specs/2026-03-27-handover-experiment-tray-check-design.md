# 接驳区实验托盘打勾与多色标签设计

## 背景

接驳区页面已经具备“任务托盘布局”和“实验托盘选择”的基础能力，但业务规则还需要进一步收口：

1. 任务详情页需要在任务编号下方直接显示该任务包含的多个实验。
2. 用户需要逐个点击实验，对当前已有托盘进行打勾选择。
3. 同一个托盘可以被多个实验重复勾选。
4. 托盘一旦被某实验勾选，就应立即显示该实验标签，且不同实验标签颜色不同。
5. 样品状态和实验归属都随托盘关系变化，不需要再单独按样品逐个分配实验。

## 目标

本轮只强化接驳区“实验选择托盘”的交互与持久化语义：

1. 任务编号下方显示该任务的全部实验入口。
2. 点击实验后，只对托盘进行打勾/取消打勾，不改变托盘布局。
3. 同一托盘可同时属于多个实验。
4. 托盘卡片根据勾选结果即时显示多色实验标签。
5. 保存托盘时，把托盘对应的样品自动挂到多个实验下。

## 业务规则

### 任务与实验显示

- 第一层仍显示任务编号。
- 第二层紧贴任务编号下方显示多个实验按钮。
- 实验按钮正文显示实验名称，不显示 `A实验 / B实验`。
- 当前选中的实验按钮使用高亮态。

### 托盘编辑态与实验勾选态

- 默认进入任务托盘编辑态。
- 任务托盘编辑态允许：
  - 调整统一上限
  - 新增托盘
  - 删除托盘
  - 样品在托盘间移动或交换
- 点击某个实验后，进入该实验的托盘勾选态。
- 实验勾选态只允许：
  - 对托盘打勾
  - 取消托盘打勾
- 实验勾选态不允许：
  - 改变托盘结构
  - 调整样品摆放
  - 新增或删除托盘

### 托盘勾选与样品归属

- 某实验勾选某托盘，表示该托盘内全部样品都属于该实验。
- 同一个托盘可被多个实验同时勾选。
- 因此同一个样品可同时属于多个实验。
- 切换到另一个实验时，托盘布局完全不变，只切换当前勾选上下文。

### 托盘标签

- 每次实验勾选成功后，托盘卡片立即增加一个实验标签。
- 标签显示实验名称。
- 同一托盘可以同时显示多个标签。
- 不同实验使用固定不同的标签颜色。
- 同一实验在所有托盘上的标签颜色保持一致。

### 保存与重置

- `保存托盘` 同时保存：
  - 任务级托盘布局
  - 实验级托盘勾选结果
  - 样品与实验的多对多关系
- `保存托盘` 不清空实验勾选和标签。
- `重新入库` 清空：
  - 托盘布局
  - 实验托盘勾选
  - 托盘标签
  - 样品挂接的实验编号

## 数据模型

### 任务托盘

任务托盘继续作为唯一的托盘布局来源：

- `task_code`
- `tray_code`
- `sample_ids`

### 实验托盘关系

继续使用实验与托盘的多对多关系：

- `task_code`
- `experiment_code`
- `tray_code`

### 样品实验关系

需要补齐样品与实验的多对多结果，来源于托盘勾选反推：

- `task_code`
- `sample_code`
- `experiment_code`

同时样品读模型需要可直接得到：

- `experiment_codes: string[]`

## 页面设计

### 头部结构

- 第一层：任务编号
- 第二层：实验按钮列表

### 托盘卡片

- 保留现有托盘标题、样品数、条码、样品标签布局。
- 托盘标题附近显示勾选按钮。
- 托盘副标题区域显示实验标签。
- 标签颜色按实验固定映射，不随托盘变化。

### 交互反馈

- 进入实验勾选态后，顶部提示文案明确为“当前为某实验托盘选择模式，只能选择托盘编号”。
- 勾选或取消勾选后，立即刷新托盘标签显示。
- 点击其他实验时，只切换当前实验，不触发托盘重排。

## 测试范围

### 前端运行时

1. 任务编号下方显示多个实验按钮。
2. 点击实验按钮进入托盘勾选态。
3. 勾选托盘后立即显示实验标签。
4. 同一托盘可显示多个不同颜色标签。
5. 切换实验不改变托盘布局与样品位置。

### 后端接口

1. workspace 返回实验按钮所需的实验列表和托盘标签信息。
2. allocate 保存实验托盘关系。
3. allocate 同时回写样品的多实验归属。
4. reload 清空实验托盘关系和样品实验归属。

## 成功标准

1. 任务编号下方可直接切换多个实验。
2. 每个实验都能对现有托盘进行打勾选择。
3. 同一托盘可被多个实验选中。
4. 托盘卡片上会显示多个不同颜色的实验标签。
5. 样品实验归属完全由托盘勾选结果自动派生，无需单独逐样品分配。
