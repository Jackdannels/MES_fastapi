# 接驳区独立页脱壳设计

## 背景

当前接驳区工作台已经替换为独立业务界面，但仍嵌在 `App.vue` 的公共外壳中。用户希望进一步舍弃原有外壳，只让接驳区工作台本身承担完整页面职责，同时保留统一的系统视觉语言，并在页面内部提供退出登录按钮。

## 目标

本轮实现以下能力：

1. `handover` 模块不再使用 `App.vue` 的侧栏与公共页头
2. 接驳区工作台内部新增系统级顶部区域
3. 顶部区域提供 `退出登录` 按钮
4. 视觉风格继续沿用现有外壳的字体、色彩、圆角、按钮和层级语言

本轮明确不做：

- 不增加“切换到中控系统”按钮
- 不改登录流程
- 不改中控系统、可视化系统、暂存间管理的外壳模式

## 交互设计

### 外层壳边界

只对 `handover` 模块做脱壳处理：

- `central` 模块继续使用现有公共外壳
- 其他非接驳区模块继续保持原状
- `handover` 模块在 `App.vue` 中直接渲染页面，不显示侧栏和公共页头

### 接驳区页顶部

接驳区工作台页面内部新增系统级头部，包含：

- 小标题 `接驳区系统`
- 主标题 `接驳区工作台`
- 说明文案
- `退出登录` 按钮

该头部位于总览和详情视图的最上方，始终可见，详情页不再依赖外壳按钮执行退出登录。

### 退出登录行为

按钮继续复用现有退出逻辑：

- 调用 `logoutSession()`
- 完成后跳转 `/login`

不新增新的认证接口。

## 视觉设计

接驳区页不再复制侧栏壳，但风格保持一致：

- 延续 `Space Grotesk` / `IBM Plex Sans` 标题体系
- 延续浅色渐变背景、玻璃感卡片、蓝橙强调色
- 延续 `eyebrow + title + subtitle + action button` 的信息结构
- 保留现有接驳区工作台主内容区布局，不重做业务区域排版

## 测试设计

### App 边界测试

验证 `handover` 模块不再使用公共外壳：

- 不显示外层品牌与侧栏
- 只渲染模块页面本身

### 接驳区页面测试

验证：

- 页面内部渲染系统级头部
- 页面内部渲染 `退出登录`
- 点击后调用退出逻辑并跳回 `/login`

## 验收标准

1. 进入 `/handover-system` 时不再显示公共侧栏和公共页头
2. 页面顶部出现接驳区自己的系统头部
3. 页面内可以直接退出登录
4. 整体视觉仍与原系统外壳风格一致
