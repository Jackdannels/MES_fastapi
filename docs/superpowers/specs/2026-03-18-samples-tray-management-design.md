# 样品管理页托盘总览临时管理设计

## 背景

当前样品管理页已经有：

- `样品流转`
- `暂存间`

但还没有一个可以直接维护托盘状态的入口。现阶段托盘状态虽然已经进入数据模型，但页面侧仍然只能通过样品流转、托盘分装和暂存派发间接影响状态，不利于联调和现场验证。

用户当前需要一个临时、直接的托盘状态管理入口，放在样品管理页内，优先满足“查看所有托盘 + 直接修改托盘状态”。

## 目标

在样品管理页新增一个临时 `托盘总览` 视图，用于：

1. 展示所有托盘对应的任务信息
2. 展示托盘当前状态
3. 直接通过下拉框修改托盘状态
4. 修改托盘状态时，同步托盘下全部样品状态
5. 修改后广播现有刷新事件，让任务页、任务总览、过程管控自动更新

## 方案

### 页面位置

在 `frontend/src/modules/samples/page.vue` 现有 tab 区里，新增第三个切换项：

- `样品流转`
- `暂存间`
- `托盘总览`

`托盘总览` 作为样品管理页内的临时业务面板，不新增独立路由。

### 数据来源

继续基于当前 `mes.samples` 快照中的 `sample.trays` 进行托盘聚合，不新建独立托盘存储结构。

聚合维度：

- `tray_code`
- `task_code`
- `tray.status`
- 同盘样品数量
- 同盘样品编号摘要

如果同一托盘挂了多个样品，则视为一条托盘记录。

### 托盘表字段

临时表格先展示以下字段：

1. 托盘编号
2. 任务号
3. 任务名称 / 试验类型
4. 当前状态
5. 样品数
6. 样品编号摘要

其中 `当前状态` 使用下拉框，选项直接复用当前正式托盘状态集合。

### 修改规则

当用户在 `托盘总览` 中修改某一托盘状态时：

1. 找到该托盘对应的所有样品
2. 更新这些样品下与该 `tray_code` 匹配的 `tray.status`
3. 将这些样品的 `sample.status` 同步为相同状态
4. 同步更新 `sample.flow_status`
5. 持久化回当前样品快照
6. 广播 `mes:samples-updated`

### 边界

本轮只做托盘状态管理，不扩展以下能力：

- 不支持新增托盘
- 不支持删除托盘
- 不支持编辑托盘内样品分配
- 不新增托盘详情抽屉
- 不新增独立托盘 API

## 验证目标

1. 能从样品管理页切换到 `托盘总览`
2. 能看到托盘对应任务信息和状态
3. 修改托盘状态后，托盘状态立即更新
4. 同托盘下样品状态也同步更新
5. 相关页面依赖刷新事件后能拿到最新状态
