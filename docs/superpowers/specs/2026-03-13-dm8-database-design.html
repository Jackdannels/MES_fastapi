MES 项目达梦数据库设计说明书（DM8，数据字典版）

基于当前真实存储结构、前端业务行为和预留 FastAPI 路由抽象出的单工厂数据库设计

1. 设计边界与结论

  • 数据库：达梦 DM8。
  • 组织模式：单工厂、单账套。
  • 范围：当前真实业务 + app/api/routes/ 预留业务域。
  • 目标：输出可直接用于建表 SQL 编写的数据字典文档。
  • 总表数：49 张。

2. 当前真实存储映射总览

当前 Key目标表迁移说明
mes.tasksBIZ_TEST_TASK、BIZ_TEST_TASK_ATTACHMENT任务主记录直接落表，附件独立，tray_codes 删除为冗余汇总字段。
mes.schedulesBIZ_TEST_SCHEDULEtask_code、device 文本关系全部替换为数值外键。
mes.samplesBIZ_SAMPLE、BIZ_SAMPLE_EVENT、BIZ_SAMPLE_TRAY、BIZ_SAMPLE_TRAY_ITEM样品主记录、事件、托盘、托盘明细完全拆表。
mes.devicesMD_DEVICE、MD_DEVICE_CONNECTION、MD_DEVICE_POINT、MD_DEVICE_MAINTENANCE设备台账、连接配置、点位、维护校准规范化。
mes.streamsBIZ_DATA_STREAM、BIZ_DATA_GAP_EVENT采集状态和缺口事件拆分。
mes.conflictsBIZ_SCHEDULE_CONFLICT需要保留处理痕迹时落表，否则可仅服务端计算。

5. 表设计（系统与组织）

11. 分阶段实施建议

  1. 第一阶段先落 MD_TEST_TYPE、MD_LAB、MD_DEVICE、BIZ_TEST_TASK、BIZ_TEST_SCHEDULE、BIZ_SAMPLE、BIZ_SAMPLE_EVENT、BIZ_DATA_STREAM。

  3. 第三阶段补主数据、仓储和 yt_* 扩展对象。
  4. 第四阶段用正式仓储实现替换当前 /api/storage 聚合 JSON 接口。
