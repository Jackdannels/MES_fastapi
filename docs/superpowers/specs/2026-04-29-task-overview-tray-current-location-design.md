# 托盘总览当前状态与位置设计

## 背景

任务/托盘总览的托盘视图当前使用“排程状态”和“实验室”两列展示托盘信息。这个口径会把任务是否已排程、排程目标实验室和托盘实际位置混在一起：托盘即使仍在接驳区，也可能因为已有正式实验室排程而显示为目标实验室。

用户确认的新口径是：托盘总览必须严格展示托盘当前真实状态和当前位置。

## 目标

- 将托盘视图表头 `排程状态` 改为 `当前状态`。
- 当前状态使用统一托盘流程推导，和样品/过程管控里的托盘流程保持一致。
- 将原 `实验室` 列改为 `当前位置`。
- 当前位置严格取托盘当前样品位置；不能因为已经排程到正式实验室就提前显示正式实验室。
- 如果托盘已排程但还未从接驳区出库，当前位置仍显示 `接驳区`。
- 托盘位于暂存间时显示具体暂存间，位于实验间时显示具体实验间。
- 空槽位继续展示占位行，但不显示“未排程”状态标签。

## 方案

在 `frontend/src/modules/task-overview/model.js` 的 `buildTrayOverviewRows` 中按托盘聚合样品位置与状态：

- 对真实托盘，读取关联样品的 `location` 和托盘状态。
- 调用 `buildTrayFlowView` 输出统一流程下的 `status` 作为 `currentStatus`。
- 当前位置从样品 `location` 聚合得到，缺失时显示 `-`。
- 任务排程只保留用于目标实验推导和实验顺序输入，不再作为当前位置来源。

组件 `TaskOverviewTrayTable.vue` 只消费模型输出：

- 表头改为 `当前状态` 和 `当前位置`。
- 真实托盘显示当前状态标签与当前位置。
- 空槽位的当前状态和当前位置显示 `-`。

## 测试策略

- 模型测试覆盖：已排程但仍在接驳区的托盘，当前位置显示接驳区而不是排程实验室。
- 模型测试覆盖：托盘在暂存间或实验室时显示具体位置，并使用统一流程状态。
- 组件测试覆盖：表头更新，空槽位不显示“未排程”状态标签。
