# 排程跨天甘特图与预计实验时间设计

**目标**

在 `排程看板` 中支持跨天实验的连续甘特条带显示，并在手动排程/编辑排程中新增 `预计实验时间` 字段（单位小时，最小刻度 `0.5`），保证排程创建、编辑、冲突校验与现有逻辑保持一致。

**现状**

- 当前甘特图按“日期 × 上午/下午”生成离散槽位，单个实验会被拆成多个独立单元。
- 手动排程依赖 `time_slot` 或 `custom_start/custom_end` 直接计算 `start_at/end_at`，没有显式的持续时长字段。
- 编辑抽屉可修改开始/结束时间，但无法直接按预计实验时长重算。

**设计决策**

## 1. 预计实验时间

- 在手动排程表单和编辑抽屉中新增 `planned_hours` 字段。
- 字段类型为数字，单位小时，`min=0.5`、`step=0.5`。
- 新建排程时：
  - `上午` 默认从 `08:00` 开始。
  - `下午` 默认从 `13:30` 开始。
  - `自定义` 使用 `custom_start` 作为开始时间。
  - 结束时间统一由 `开始时间 + planned_hours` 计算。
- 编辑排程时同样允许修改 `planned_hours`，并重新计算 `end_at`。
- 旧数据若无 `planned_hours`，继续由 `start_at/end_at` 反推小时数用于展示和编辑默认值。

## 2. 跨天甘特图

- 一个排程在甘特图中显示为同一行内的一条连续 bar，而不是多个重复按钮。
- 甘特图仍保留半天粒度（上午/下午）作为列头，但渲染模型从“逐槽 label”升级为“槽位背景 + 跨列段”。
- 每条 bar 具有：
  - 起始槽索引
  - 结束槽索引
  - 状态类名（已排程/运行中/已完成/冲突）
  - 显示文案（任务编号）
  - tooltip（任务编号、开始时间、结束时间、持续小时）
- 如果实验跨越当前 3 天窗口，日期窗口自动扩展到能完整包含最晚结束时间。

## 3. 冲突与点击行为

- 冲突继续基于真实 `start_at/end_at` 判断，不按槽位简化。
- 若同一实验室同一时间段有多个实验重叠，则保留冲突样式，并显示首个任务编号与冲突数量提示。
- 甘特图点击行为保持：点击条带打开排程编辑抽屉。
- 空闲槽位仍保留为浅灰背景，用于和实验条带区分。

## 4. 兼容性

- `retention`（暂存间）保留当前特殊逻辑，不强制使用 `planned_hours` 覆盖实时锁定行为。
- 已有测试需补齐：
  - 新建跨天排程的时长计算
  - 编辑时长后结束时间重算
  - 甘特图连续条带跨越多天
  - 窗口自动扩展到覆盖跨天实验
