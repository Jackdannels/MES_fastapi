# Process Control Start Experiment Tray Flow Design

**Goal**

在“试验过程管控”页为每个实验室增加 `开始实验` 操作，并在 `查看任务` 抽屉中展示托盘级当前批次与剩余批次信息，流程图口径与样品管理中的统一流程图保持一致。

**Current Context**

当前过程管控页已经支持：

- `总览 / 实验中 / 已排程 / 空闲` 顶部筛选
- 实验室卡片查看任务摘要

但仍缺少两个关键能力：

- 无法从过程管控页直接启动实验
- 无法在任务抽屉中看出“当前实验的是哪些托盘、还剩哪些托盘”

**Decision**

新增卡片级 `开始实验` 按钮，并采用“按当前准备就绪托盘批次启动”的规则：

- 不弹二次勾选面板
- 点击后仅把当前状态为 `实验准备就绪` 的托盘改为 `实验进行中`
- 其他托盘状态不变
- 如果当前任务下存在任何 `实验进行中` 托盘，则本轮不允许再次点击开始实验

按钮启用条件：

- 当前任务下至少有 1 个托盘状态为 `实验准备就绪`
- 当前任务下没有任何托盘状态为 `实验进行中`

成功后提示：

- `当前开始进行 {本次启动托盘数} 个托盘，剩余 {剩余托盘数} 个托盘。`

其中：

- `本次启动托盘数` = 本次由 `实验准备就绪` 转为 `实验进行中` 的托盘数量
- `剩余托盘数` = 当前任务下尚未进入本轮实验且尚未完成的托盘数量

**Drawer Design**

`查看任务` 抽屉保留原任务摘要，并新增三块托盘信息：

- `当前实验托盘`
  - 显示当前状态为 `实验进行中` 的托盘
- `待下一轮托盘`
  - 显示当前任务下尚未完成且未在本轮实验中的托盘
  - `实验准备就绪` 托盘标识为 `可启动`
- `托盘流程图`
  - 点击某个托盘后，右侧展示该托盘的统一流程图
  - 节点顺序和样式复用样品管理模块的 `SAMPLE_FLOW_STEPS`

默认选中的托盘优先级：

1. 第一个 `实验进行中` 托盘
2. 第一个 `实验准备就绪` 托盘
3. 第一个未完成托盘
4. 第一个托盘

**Architecture**

- `frontend/src/modules/process/useProcessLabs.js`
  - 负责托盘级状态聚合、开始实验动作、成功提示与抽屉托盘选择状态
  - 通过 `persistSnapshot()` 写回更新后的 `mes.samples` 与 `mes.tasks`
- `frontend/src/modules/process/page.vue`
  - 卡片底部增加 `开始实验`
  - 抽屉内增加托盘批次区与托盘流程图区
- `frontend/src/modules/process/styles.css`
  - 补充卡片双按钮区、提示区、托盘列表和流程图区样式
- `frontend/src/modules/samples/samplesFlowModel.js`
  - 继续作为统一流程步骤与托盘流程视图构建的复用来源
