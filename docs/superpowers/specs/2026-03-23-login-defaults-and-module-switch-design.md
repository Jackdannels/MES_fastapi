# 登录默认值与模块切换退出弹窗设计

## 背景

当前系统登录页需要手动输入账号密码，且各功能页点击“退出登录”会立即清理会话并回到登录页。用户希望：

- 登录页默认填充固定演示账号 `admin / 123`
- 各功能页点击“退出登录”时改为弹出菜单弹窗
- 弹窗内同时提供：
  - `取消`
  - `彻底退出`
  - 模块下拉框
  - `切换其他界面`
- 选择目标模块后点击 `切换其他界面`，直接跳到对应模块首页，并保持已登录状态

## 目标

- 登录页默认填充演示账号，不需要用户每次手工输入
- 保留现有登录协议和后端接口
- 统一共享壳层页面与接驳区页面的退出行为
- 切换模块时不清理 session，不重新登录
- 彻底退出时仍保持当前的后端退出流程

## 非目标

- 不修改登录按钮文案和登录页面整体布局
- 不引入新的权限模型
- 不新增新的模块键或路由
- 不将切换模块操作改成重新访问登录页

## 交互设计

### 登录页默认值

- 登录页初始值：
  - 用户名：`admin`
  - 密码：`123`
- 用户可以手动修改这两个值
- 默认界面选择维持现有 `central`
- 默认值只放在登录表单逻辑层，不直接硬编码到模板层

### 退出弹窗

- 任意功能页点击 `退出登录` 按钮时，打开统一弹窗
- 弹窗固定显示：
  - 一个模块下拉框
  - `取消` 按钮
  - `彻底退出` 按钮
  - `切换其他界面` 按钮
- 下拉框初始值为当前模块
- 如果用户未切换到其他模块就直接点击 `切换其他界面`，在弹窗内显示提示：`请选择其他界面`

### 操作语义

- `取消`
  - 关闭弹窗
  - 不改变当前 session、路由和模块
- `彻底退出`
  - 调用现有 `logoutSession()`
  - 清理会话
  - 跳转到 `/login`
- `切换其他界面`
  - 不调用 `logoutSession()`
  - 保持当前 session
  - 根据下拉框值跳转到目标模块首页

## 模块首页映射

沿用现有模块路由映射：

- `central` -> `/`
- `handover` -> `/handover-system`
- `visual` -> `/visualization`
- `staging` -> `/staging-management`

## 实现方案

### 共享配置

在前端共享认证/模块配置中统一维护模块标签映射，供：

- 登录页界面下拉框
- 共享退出弹窗
- App 模块标题展示

### 共享退出弹窗组件

新增共享组件，负责展示：

- 标题
- 当前模块可见的模块切换下拉框
- 错误提示
- `取消 / 彻底退出 / 切换其他界面`

组件本身只处理展示和表单选择，通过事件把操作结果回传给宿主页面。

### 共享页面壳接入

在 `App.vue` 中接管大部分模块的退出行为：

- 点击 `退出登录` 打开弹窗
- 彻底退出时走现有逻辑
- 切换模块时只做路由跳转

### 接驳区页面接入

接驳区当前是裸模块页，不经过 `App.vue` 的公共壳，因此在接驳区页面自身接入同一个共享弹窗组件和相同的操作语义。

## 错误处理

- 切换目标仍是当前模块：提示 `请选择其他界面`
- 切换时若路由跳转失败：保留当前页面并展示通用错误提示
- 彻底退出失败：沿用现有 `logoutSession()` 的 finally 逻辑，仍回登录页

## 测试策略

- 登录表单组合函数测试：
  - 初始默认账号密码
  - 登录成功跳转逻辑不受影响
- 共享退出弹窗组件测试：
  - 打开时显示当前模块为默认选项
  - 点击取消触发关闭
  - 选中当前模块时点击切换显示错误
  - 选中其他模块时点击切换发出正确事件
  - 点击彻底退出发出正确事件
- `App.vue` 运行时测试：
  - 点击退出登录先打开弹窗
  - 选择切换目标后直接路由跳转
  - 彻底退出才调用 `logoutSession`
- 接驳区页面运行时测试：
  - 与共享壳保持相同退出弹窗行为

## 验收标准

- 登录页默认出现 `admin / 123`
- 所有功能页点击 `退出登录` 都先打开弹窗
- 弹窗始终显示下拉框、取消、彻底退出、切换其他界面
- 切换到其他模块时不回登录页且保持已登录
- 彻底退出时仍回到登录页
