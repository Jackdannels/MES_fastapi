# 排程任务准入、同任务连续排程与删除后重排设计

## 背景

排程页当前已经支持：

1. 多实验任务逐个实验排程。
2. 甘特图查看设备占用。
3. 任务详情查看排程信息。
4. 冲突提示与确认排程。

但现阶段还有三个直接影响排程效率的缺口：

1. 一个任务排完第一个实验后，表单会整体重置，连续排同任务剩余实验时仍需重新选择任务。
2. 尚未在中控预分装或接驳区保存托盘方案的任务，仍可能出现在排程入口中，不符合业务流程。
3. 任务详情弹窗只能查看当前排程，不能直接删除并重新排程。

## 目标

本轮只在 `schedule` 模块内强化三个行为：

1. 排程任务下拉只显示已经保存托盘方案的任务。
2. 同一任务成功排完一个实验后，保留当前任务编号，其余排程字段按默认规则重置。
3. 任务详情弹窗支持删除当前排程，并支持“删除后重新排程”。

## 业务规则

### 任务准入

- `接驳区排程` 页签中，仅显示“已预接驳/接驳”的任务。
- “已预接驳/接驳”按“已保存托盘方案”判定，满足任一条件即可：
  - `task.tray_codes` 非空
  - `sample.trays` 中存在当前任务托盘记录
  - `experiment_trays` 中存在当前任务的实验托盘关系
- 未保存托盘方案的任务不显示在排程任务下拉中。
- `暂存间排程` 页签保持现有内部暂存任务逻辑，不使用这套准入限制。

### 同任务连续排程

- 当用户成功为某任务确认排程一个实验后：
  - 保留 `任务编号`
  - 重新计算该任务剩余可排实验
  - `实验编号` 自动切到下一个仍可排的实验；若没有剩余实验则置空
  - `实验室` 清空
  - `排程日期`、`时段`、`开始时间`、`预计实验时长` 重置为默认值
- 如果当前任务已无剩余实验：
  - 仍保留任务编号
  - 实验编号为空
  - 页面提示“当前任务已无可排实验”
- 上述规则同样适用于冲突确认框中点击 `确认排程` 的场景。

### 任务详情中的删除与重排

- 当前“任务详情”弹窗底部新增两个动作：
  - `删除排程`
  - `删除后重新排程`
- `删除排程`
  - 删除当前这条排程记录
  - 更新任务状态、甘特图、排程清单和冲突列表
  - 关闭任务详情弹窗
- `删除后重新排程`
  - 先删除当前排程
  - 再把该排程的关键信息回填到顶部排程表单
  - 关闭任务详情弹窗
  - 页面停留在可立即重新提交的状态
- 回填字段包括：
  - 任务编号
  - 实验编号
  - 实验室
  - 排程日期
  - 时段或自定义开始时间
  - 预计实验时长
- 删除后若该实验重新变为“未排程”，实验下拉应立即恢复该实验选项。

## 数据与状态设计

### 准入判断

- 准入判断优先在排程模型层完成，避免在页面层重复拼装。
- 模型层需要新增一个“任务是否已保存托盘方案”的派生判断，统一消费：
  - `tasks`
  - `samples`
  - `experiment_trays`

### 表单重置

- 现有 `resetScheduleForm()` 需要拆成两种语义：
  - `resetScheduleForm()`：完全重置
  - `resetScheduleFormForSameTask(taskCode)`：保留任务并初始化下一实验
- 这样可以同时兼容：
  - 页面初始加载
  - 手工点击清空
  - 成功排程后继续排同任务

### 删除后重排

- 删除后重排不是“编辑抽屉”，而是“详情弹窗里的快捷回填”。
- 需要新增一个把现有排程反向映射为顶部手动排程表单的转换函数，避免页面手工拆时间字段。

## 页面设计

### 排程表单

- 任务下拉文案不变，但可选任务范围缩小为“已保存托盘方案”的任务。
- 成功排程后保留任务编号，让排程员连续完成同任务的多个实验。

### 任务详情弹窗

- 详情信息区保持现有只读表单风格。
- 底部新增操作按钮区：
  - `删除排程`
  - `删除后重新排程`
- `删除后重新排程` 视觉上应比单纯删除更强调，避免用户误用。

## 测试范围

### 模型测试

1. 未保存托盘方案的任务不会进入排程任务下拉。
2. 已有 `task.tray_codes`、`sample.trays` 或 `experiment_trays` 的任务会进入排程任务下拉。
3. 删除排程后，对应实验会重新出现在实验选项里。

### 组合逻辑测试

1. 成功排程后保留当前任务编号，只重置其余排程字段。
2. 若仍有剩余实验，自动切到下一个实验。
3. `删除后重新排程` 会删除当前排程并把表单回填到可再次提交的状态。

### 页面运行时测试

1. 排程任务下拉只显示已保存托盘方案的任务。
2. 连续排同任务多个实验时，无需重复选择任务。
3. 任务详情弹窗显示 `删除排程` 与 `删除后重新排程`。
4. 点击 `删除排程` 后，当前排程从清单与甘特图中消失。
5. 点击 `删除后重新排程` 后，顶部表单被正确回填。

## 成功标准

1. 未完成预分装/接驳保存的任务不会进入接驳区排程。
2. 同一任务排完一个实验后，排程员可以连续排下一个实验，不需要重新选任务。
3. 任务详情弹窗支持直接删除排程并快速重新排程。
