# 三合一窗口 v1.2.0 本机验证

日期：2026-11-07。

## 变更

1. 中控、LIMS、上位机三个页面合并为一个窗口中的原生页签。模拟器仍使用现有服务，MQTT/RabbitMQ 业务规则未调整。
2. 模拟器页签可通过配置隐藏；切换页签保留已初始化的容器与页面状态。
3. 窗口模式使用 Windows 原生最小化、最大化／还原和关闭按钮；全屏时提供对应按钮及退出全屏入口。
4. “下载目录”改名为“打开下载文件夹”，作用于当前页签。
5. 控制中心三合一模式只启动一个窗口，可直接唤起指定模拟器页签。

## 测试范围

结果：客户端、三合一、三套独立 EXE 兼容性和既有桌面工具共 **51 项测试通过**；旧浏览器管理专项也通过。

- 原有客户端生命周期与三套独立 EXE 兼容性回归。
- 真实 LIMS、上位机页面在嵌入页签中的脚本执行及接口轮询。
- 页签切换后容器进程保留，关闭主窗口后全部所属 WebView2 进程退出。
- 模拟器配置关闭、初始化期间关闭、控制中心单窗口打开与指定页签唤起。
- 最小化、还原、最大化、全屏切换保留页面；全屏覆盖当前显示器；页签栏没有被工具栏遮挡。
- 旧浏览器窗口管理专项回归。

测试使用本机隔离端口、临时数据和测试服务脚本。真实服务、已安装程序、数据库和其他工位未迁移或替换。

## 验证中修正

- 修复原生 Dock 控件布局顺序，避免工具栏覆盖页签栏，并添加页签可见性回归。
- 修复第二显示器上的全屏坐标偏移，最大化边界采用显示器相对坐标。

图形自动化曾读取到非目标窗口，已停止该部分输入；最终窗口行为和页签布局约束由编译后原生程序测试验证。
