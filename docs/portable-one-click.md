# MES Docker 离线交付包 · 2026.10.21-r1

包含当前代码重新构建的主系统、LIMS 模拟器、上位机模拟器，当前电脑停写业务数据快照，以及控制中心 v2.7.2、工作台设置和终端管理三个 Windows 程序。

## 在新 PC 上部署

1. 新 PC 安装并完成 Docker Desktop 的 Linux 引擎初始化；本包不代替 Docker Desktop / WSL 的安装及必要系统重启。
2. 将**整个交付文件夹**复制到新 PC 的本机磁盘。保留此目录作为运行目录，部署完成后也不要删除或随意移动它。运行组件及本机配置均在该目录中，不需要原项目源码、Python、Node 或 Conda。
3. 双击 **01-Deploy.cmd**。接受 Windows 管理员权限提示后，脚本自动校验文件、加载三个镜像包、生成本机独立密码、恢复附带业务数据、启动全部服务并检查连接和登录，最后创建三个桌面快捷方式。
4. 安装完成会打开本机受限的 `.local/MES-connection.txt`，其中是该 PC 实际 MES 地址和账号密码，同时用默认浏览器打开 MES 和 LIMS 页面。工作台首次注册、控制中心和终端管理使用此密码。
5. 双击桌面的 **MES控制中心_v2.7.2_Docker版** 使用。局域网地址显示在首页与“关于与访问地址”。

整个操作可能持续数分钟，尤其是第一次加载镜像。保持脚本窗口开启；错误会显示在窗口及 `.local/logs`。数据恢复成功后再次运行安装入口只检查、启动并重建桌面入口，不会再次覆盖数据库；恢复中断后拒绝向部分恢复的数据继续覆盖，应先检查日志。

## 其他双击入口

| 文件 | 功能 |
|---|---|
| `01-Deploy.cmd` | 首次部署；完成后可重复检查和启动 |
| `02-Create-Desktop.cmd` | 重新生成三个桌面快捷方式 |
| `03-Connection-Info.cmd` | 查看此 PC 的 MES 地址和实际登录凭据 |
| `04-Verify.cmd` | 校验交付文件是否完整，不启动服务 |

三个桌面程序运行副本保存在 `.local/desktop-tools`，桌面是对应快捷方式。只安装桌面入口不复制其他电脑的工作台注册身份，固定工作台在各自电脑重新注册。

## 网络与端口

默认 Web 端口 15173。启动时自动检测当前有线 / Wi-Fi IPv4、监听主机网卡并填写公开地址与 Origins；管理员权限用于设置仅专用网络、本地子网的 Web 防火墙规则。其他工作站通过 `http://MES主机IP:15173` 访问，跨网段或共享目录仍需现场网络配置。

本机 API 为 18000，LIMS 18900，上位机 18899，MySQL 13306，MQTT 11883，RabbitMQ 管理 15673。首次自动生成的 Compose 项目名为 `mes-portable-2026-10-21-r1`，与旧版默认项目的数据卷分开。若端口已被其他部署占用，安装器会停止并提示；请先停止目标 PC 上准备替换的旧部署，保留其数据备份。此入口不覆盖另一套已运行或已有数据卷的部署。

可在首次安装前用底层 `release-2026.10.21-r1/scripts/deploy/Mes-Portable.ps1 -Action Initialize` 生成环境文件，按需修改端口后再双击安装入口；不要更改已经有数据的 Compose 项目名或重新生成凭据。

## 数据来源与备份

附带快照来自本次打包时的当前电脑，具体时间、表行数、文件校验见 `data-backup-2026.10.21-r1/data-manifest.json`。它不包含此前已迁移 PC 在快照之后新增的数据。如需保留另一台 PC 的更新业务记录，应先从该 PC 生成最新停写备份，再安排迁移。

数据库、报告、LIMS SQLite 都包含在数据包内；RabbitMQ 原始运行目录和模拟器内存中的在途试验不跨平台迁移。高低温湿热二室安装样品/夹具就绪的本地模拟例外保留，试验准备/启动/结束继续使用 MQTT。

v2.7.2 控制中心支持关闭系统时同步关闭由它打开的 MES、LIMS、上位机模拟器三个网页，重启成功后重新打开页面。包含此前的按钮恢复修复和中心进度弹窗：操作期间为估算进度，实际完成后才显示 100% 并自动隐藏。关闭服务保留容器及数据卷，后续启动使用快速就绪检查和 Web 资源压缩。

Docker 控制脚本在启动或重启成功后，统一打开 MES、LIMS、上位机模拟器三个网页（仅主系统模式打开 MES）；使用当前部署环境文件中的实际 MES 公开地址和已配置的 LIMS 和上位机端口。首次部署入口也会在服务检查通过后自动打开网页。

本次离线包的本机验证及适用范围在 verification 中。干净新 PC、操作系统重启、自启动和其他电脑局域网访问仍需现场验收。
