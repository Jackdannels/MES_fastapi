# MES 综合测试终端

双击 `MES综合测试终端.exe`，使用开发测试账号登录。通过业务页面右上角的“退出登录”入口打开切换窗口，选择目标模块和试验间后，点击“切换其他界面”。

- 中控：中控管理。
- 试验间：全部 11 个试验间。
- 其他工位：可视化管理、接驳区系统、暂存间系统、外观检测间系统。

共 16 个业务页面；菜单不含上位机和 LIMS 模拟器。页面切换沿用服务器账号会话和权限校验。测试终端具有独立的本机登录目录，普通工位仍按固定工位申请审批。

测试客户端不增加独立的左侧切换栏或顶部横条，业务页面使用与正常终端相同的布局。中控页面自身的业务菜单保持原样。

“开发测试”表示此客户端支持多页面切换，业务操作使用当前连接的 MES 环境。

服务器地址位于本文件夹 `mes-client.json` 的 `serverUrl`。从其他电脑运行时请填写 MES 主机的局域网地址。完整复制文件夹，保留 DLL、EXE.config 和配置文件；需有 .NET Framework 4.8 与 WebView2 Runtime。

界面按页面主题同步深浅配色。重复打开会唤起同一测试窗口；关闭测试终端只关闭本窗口，后台 MES 服务继续运行。

## 页面缩放

所有 16 个业务页面的顶部均提供缩放控件，放在“刷新”左侧：`缩放 − 125% + | 重置`。首次打开默认 100%。

- **Ctrl + 滚轮**：向上放大、向下缩小；普通滚轮继续滚动页面和表格。
- **− / +** 或 **Ctrl + 加号 / 减号**：按相同档位调整。
- **重置** 或 **Ctrl + 0**：恢复 100%，不会刷新页面；100% 时重置按钮禁用。
- 档位为 50%、67%、75%、80%、90%、100%、110%、125%、150%、175%、200%；达到上下限后禁用对应按钮。
- 刷新、切换业务页面、重新连接及关闭重开后保留当前比例。比例按本机测试终端保存，全部页面共用，不跟随业务账号切换。
- 工具栏的比例来自实际 WebView2 页面缩放。若暂未收到客户端读数则显示 `—`，收到读数后即可操作。登录页支持快捷键，但不显示业务工具栏。

本机偏好保存在 `%LOCALAPPDATA%\MESDesktopClient\<终端标识>\page-zoom.json`，与安装目录的 `mes-client.json` 分开。偏好文件缺失、损坏或比例无效时，恢复默认 100%。需同时更新配套 EXE 和服务器前端，旧版客户端不会显示新控件。

显示仍使用逐显示器 DPI 适配。页面比例与 Windows 显示缩放分开计算，例如 Windows 显示缩放为 125%、页面默认大小时，控件显示 100%。请保留配套的 `MES综合测试终端.exe.config`，只复制 EXE 会丢失高 DPI 配置。显示诊断可从运行中的客户端 `--status` 输出或本机客户端日志的 `display` 记录读取。
