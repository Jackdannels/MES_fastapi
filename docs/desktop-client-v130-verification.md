# v1.3.0 单行导航与文件夹内迭代

日期：2026-11-07。

## 界面

- 同一顶部栏直接显示“MES中控管理 / LIMS模拟器 / 上位机模拟器”，移除重复标题及第二层页签栏。
- 移除客户端“打开下载文件夹”“刷新”“全屏”按钮及自定义全屏模式。
- 使用 Windows 原生标题栏管理最小化、最大化／还原、关闭，默认最大化。原有 `fullScreen` JSON 兼容解释为最大化偏好。
- 页面内的刷新、下载与打印功能不改动；下载完成后状态栏显示保存位置。

## 版本迭代

`scripts/update_desktop_client.ps1` 支持直接更新已解压目录：校验源清单、备份原文件、正常关闭目标客户端、替换程序、重新生成已安装文件清单，并保留配置原始字节。每次更新留存版本和备份位置，支持之后继续迭代。复制或验证失败时恢复备份。

## 验证范围

- 三个入口在同一栏、入口名称与数量正确，页面切换保留独立容器，关闭时释放所属进程。
- 原生最小化、最大化和还原保留页面。
- 原有中控与模拟器客户端生命周期、控制中心联动回归。
- 更新保留配置与额外用户文件、备份原程序；损坏来源在替换前被拒绝；运行中的指定客户端可以正常关闭并重新启动。

测试使用临时端口、隔离配置及测试服务脚本；实际更新仅替换用户指定解压目录的客户端程序和说明文件，不修改业务服务、数据库或其他工位。
