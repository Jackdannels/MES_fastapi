# 交付版5826信息化管理系统v1.2

包含本次源码构建的 MES 前后端、MySQL、RabbitMQ/MQTT、LIMS 模拟器、上位机模拟器、控制中心 v2.9.0、中控管理客户端 v1.7.0，以及 11 个试验间和 4 个其他工位的客户端。应用镜像与停写业务快照分目录保存，并分别校验。

## 安装

双击“交付版5826信息化管理系统v1.2_安装程序.exe”。

1. 选择新的或空的安装文件夹，可使用中文和空格。
2. 选择主机安装或工位安装，按需勾选试验间、可视化、接驳区、暂存间、外观检测间。
3. 主机安装可浏览选择 Docker Desktop.exe，留空时自动识别默认、按用户及自定义安装位置；随后选择当前有线/Wi-Fi 网卡，并确认公开访问地址和端口。工位安装填写已运行的 MES 主机地址。
4. 安装器先检查 Docker Linux 引擎；未就绪时在解压前显示中文原因。环境就绪后自动完成解压校验、加载镜像、生成配置、恢复数据、启动服务及创建快捷方式，无需逐个运行多个脚本。
5. 安装成功后保留勾选“打开控制中心”，即可直接进入；日后双击桌面控制中心即可管理系统。中控管理仍可单独双击启动。

主机需要 Windows x64 和已安装初始化的 Docker Desktop Linux 引擎。目标机无需 Python、Node、Conda 或 C# 编译器。WebView2 离线安装程序随包提供，系统已具备时复用现有运行库。

MES 安装目录始终允许自定义，支持 D 盘、中文及空格路径。Docker Desktop 也可安装在其他磁盘；首次 WSL 初始化、Docker Desktop 自身的授权或重启提示需按该软件要求完成，MES 安装器不代替这些系统操作。

## 安装中断与继续

中途失败会显示具体步骤、失败原因和日志路径。处理原因后，双击所选安装目录中的 **继续完成安装.cmd**，会按原来的地址和工位选择继续，保留已生成的账号密码；完成后自动打开控制中心。已完成安装时该入口不会重复恢复数据库。

详细日志位于 `package/.local/logs/install-*.log`、`deploy-*.log`，最新错误说明位于 `last-install-error.txt`。若恢复过程中断，原有的部分恢复保护继续生效，需要先检查日志，不能直接覆盖部分恢复的数据。

退出确认、浏览目录、准备安装及失败提示均使用中文。安装程序只向普通用户提供统一安装/续装入口，部署脚本保存在内部资源目录。

## 安装目录

```text
选定安装目录/
  管理端/
    MES控制中心_Docker版.exe
    MES工作台设置_Docker版.exe
    MES终端管理_Docker版.exe
    central-client/MES中控管理.exe
  工位客户端/
    盐雾试验室/MES盐雾试验室.exe
    冲击一室/MES冲击一室.exe
    ...仅生成选中的工位...
  package/              离线部署资源及本机配置、日志
  安装记录.json
```

中控可由控制中心“打开中控管理”启动，也可在服务运行时双击中控 EXE 或快捷方式启动；同一安装内重复打开会唤起已有窗口。单独关闭中控保留后台服务。关闭控制中心会确认并停止系统，需要保留服务时请最小化。

同一 Windows 用户重复启动同一安装目录的控制中心时，提示“控制中心已打开。”并唤起已有窗口，不创建第二个窗口或重复操作服务。此行为也适用于开发测试版控制中心。

工位文件夹包含独立 EXE、JSON 与运行组件，复制时保留整个文件夹。在新电脑/新 Windows 用户中首次使用需管理员绑定，不复制其他工位的本地登录身份。各工位共享同一 MES 后台与数据库；勾选不改变实验室业务规则。

## 数据与配置

业务数据使用 Docker 持久化卷；所选安装目录保存程序、配置、日志和交付快照。内置快照来自构建时停止写入的原生服务，详细时间、表行数及哈希见 `data-backup-版本/data-manifest.json`。重复恢复拒绝覆盖已有数据库或卷；失败保留数据与诊断文件。

主机独立凭据位于 `package/release-版本/.tmp/portable.env`。控制中心系统配置显示实际文件中的重要参数，并提供中文释义。原项目 `.env` 和其他安装的凭据不会随应用镜像分发。主机连接说明位于 `package/.local/MES-connection.txt`，请妥善保管。

安装器没有删除业务数据的卸载操作。移动安装目录前先停止系统；迁移数据应使用备份恢复流程。端口占用时安装会停止并报告，不关闭其他部署。工位客户端安装只连接指定服务器，不部署数据库或修改远程业务数据。

全部实验室的实验准备、开始和结束使用 MQTT；高低温湿热二室的本地装样及夹具就绪例外继续保留。
