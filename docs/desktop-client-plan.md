# MES 固定工位客户端方案与分阶段实施

日期：2026-11-06；更新：2026-11-07

2026-11-08：工位包已升级 v1.7.0，并在桌面原总目录内更新。15 个非中控工位已在当前 Windows 用户绑定固定终端自动进入；去掉单页原生页签，除可视化外直接全屏，页面“关闭”和 Alt+F4 统一确认。详见 [v1.7.0 本机验证](desktop-client-v170-verification.md)。

最新调整：两个模拟器属于临时联调需求，中控已支持可关闭的三合一页签界面；Windows 窗口按钮和当前显示器全屏切换已实现。详见 [三合一验证记录](desktop-client-combined-verification.md)。原三套独立 EXE 保留为兼容构建选项。

2026-11-07 后续调整：客户端已使用标准 Windows 最大化窗口；中控控制中心升级到 v2.8.2，退出时确认并同步关闭系统。新增 v1.6.0 工位包：11 个实验间、可视化、接驳区、暂存间和外观检测间，按每个工位一个文件夹生成在桌面总目录。本轮仍为本机测试，未执行其他电脑迁移或真实终端注册。用法见 [专用客户端](desktop-client.md)。

## 目标

使用 Windows Forms + WebView2 承载现有 MES 网页。第一批交付中控专用客户端，启动默认全屏，不显示浏览器地址、收藏和标签栏，页面内保留中控业务导航，取消客户端中的操作台模式切换。

共用一套客户端代码和版本；服务器地址与固定模块由部署配置确定。IP 用于部署清单和连通性，现有终端 ID 与注册凭据用于固定终端身份。后续实验室、交接、暂存和看板客户端沿用这套内核。

中控第一阶段沿用现有管理员登录。当前服务端要求中控终端管理使用非终端管理员会话，因此中控不直接改成固定终端自动登录。实验室等现有固定终端继续沿用注册和票据机制。

## 架构

- `tools/desktop-client`：客户端配置、进程通信、窗口和 WebView2 容器。
- `scripts/build_desktop_client.ps1`：校验固定 SDK、编译 x64 客户端与生成交付清单，支持缓存包离线构建。
- 控制中心：检测同目录中控、LIMS 和上位机专用客户端，分别打开和关闭；缺少某一客户端时保留原浏览器入口。
- 前端：读取由客户端在文档创建前注入的固定模块信息，固定中控登录入口，退出登录不再提供切换操作台。
- 服务端与业务数据：继续使用现有 FastAPI、MySQL、MQTT 接口及状态校验。

## 阶段一：中控专用客户端

交付：

1. 默认全屏、专属名称和图标、明确的退出界面入口。
2. 可配置服务器地址，独立用户数据目录；地址改变不作为新的工位身份。
3. 固定中控登录和业务入口，普通浏览器访问的原有流程保持可用。
4. 限制主窗口跳往配置站点之外；处理新窗口、下载与运行库缺失提示。
5. 连接失败提示、手动重试与关闭时取消恢复任务。

验收：能编译和独立启动；同源登录、中控路由、主题、排程和文件下载正常；没有模式切换；离线或缺运行库时有明确提示。

## 阶段二：生命周期与控制中心联动

交付：

1. 同一客户端配置只打开一个主窗口，重复启动唤起已有窗口。
2. 使用当前 Windows 用户范围的本机通信处理状态、唤起、关闭。
3. 管理端关闭以实际进程退出为完成条件；不存在的实例关闭视为已完成。
4. 主动退出先停止恢复，再释放 WebView2，退出程序，不按进程名批量结束浏览器。
5. 控制中心启动、重启、关闭和访问地址入口识别中控客户端；旧安装仍可使用原浏览器入口。

验收：重复打开、独立关闭、控制中心重新打开后的关闭、立即重启、关闭期间初始化/重连、普通浏览器隔离。

## 阶段三：离线交付与回归

交付：

1. 固定 SDK 版本与哈希；包内含受管程序集及 x64 加载器。
2. 可附带经过签名校验的 Evergreen 离线安装器或固定版本运行库；不静默改变目标机环境。
3. 桌面工具构建可选择包含中控客户端；生成哈希清单、配置示例和使用说明。
4. 运行聚焦的客户端、控制中心、前端和部署测试。

验收：交付目录校验通过；没有源码、Node 或 SDK 的环境可使用已准备的客户端和运行库；实际新电脑、开机恢复和目标网段测试作为现场验收记录。

## 后续迁移阶段

2026-11-07 用户明确要求当前不迁移，仅在本机测试。因此当前扩展范围是 LIMS 和上位机模拟器专用 EXE 及三窗口生命周期联动；正在使用的程序、服务、数据与部署配置保持原状。

中控验收后，再按实际工位清单为实验室、交接、暂存、外观和看板生成固定角色配置，接入现有终端注册、心跳和远程命令。复制交付包时每台电脑单独注册，不复制其他终端的凭据或用户数据目录。具体 IP、实验室和电源控制权限需要现场配置。

## 关闭语义

- 退出界面：关闭本客户端，MES 服务与实验流程继续由服务器维护。
- 关闭系统：现有控制中心停止本机服务并关闭其管理的界面。
- 关闭远端终端：后续通过已有终端命令链路管理，不与本机窗口退出混用。
