# 5826信息化交付v1.3

双击 **5826信息化交付v1.3_安装程序.exe** 安装。交付为 Windows x64 的 Docker 离线安装包，控制中心 v2.10.0、工位客户端 v1.8.0。

## 安装步骤

1. 选择新的或空的安装文件夹，支持自定义磁盘、中文和空格路径。
2. 选择主机、工位或自定义安装。主机包含 MES 前后端、MySQL、RabbitMQ/MQTT、LIMS 与上位机模拟器、控制中心和独立中控管理。
3. 按需选择 11 个试验间及可视化、接驳区、暂存间、外观检测间，共 15 个工位。每个选中工位安装到独立文件夹，并包含对应工位 EXE、`MES终端接入.exe`、配置及运行组件。
4. 主机安装可浏览指定 Docker Desktop.exe，也可留空自动识别。选择现场有线/Wi-Fi 网卡并确认 MES 公开地址和端口；工位电脑填写已运行的 MES 主机地址。
5. 安装器先检查 Docker Linux 引擎，再解压、校验、加载镜像、配置、恢复数据、启动服务和创建快捷方式。安装完成即可打开控制中心。

目标机需要已安装初始化的 Docker Desktop Linux 引擎。WebView2 离线运行库随包提供。无需项目源码、Python、Node、Conda 或 C# 编译器。

│  │  └─ MES终端接入.exe

├─ package/               离线部署资源、配置及日志

交付不包含本机开发环境、综合测试终端或独立的通用接入文件夹。复制工位时保留整个文件夹。

## 工位申请与重置

首次双击工位 EXE 自动进入接入流程，也可运行同目录的 `MES终端接入.exe`。窗口固定对应工位；填写服务器地址、核对电脑名称后提交申请，无需输入管理员密码。

管理员在控制中心“终端管理 → 绑定申请与记录”中审批。首次同工位审批且文件校验成功后，可直接激活当前工位文件夹；重置、改派或文件不匹配时生成新的桌面工位目录。重置后的旧凭据和会话失效，业务数据保留。

工作机 IP 可自动获取；MES 主机地址应稳定。凭据使用当前 Windows 用户加密保存，不随文件夹复制到其他电脑。

## 控制中心

提供主项目深色、浅色两种主题；左侧底部切换。终端列表支持搜索、状态筛选、排序和详情，常用操作为“刷新界面、重置绑定”，其他操作位于“更多操作”。

同一安装重复打开控制中心时提示“控制中心已打开。”并唤起已有窗口。中控管理可由控制中心或独立 EXE 启动。关闭中控保留服务；关闭控制中心会确认并停止系统，需要保留服务时请最小化。

## 数据、配置与继续安装

内置业务快照来自构建时停写的本机 MES 服务，快照时间、源表行数和校验见 `package/data-backup-版本/data-manifest.json`。应用镜像与业务快照分开存放和校验。

每台主机独立生成凭据，配置在 `package/release-版本/.tmp/portable.env`。控制中心系统配置显示实际重要配置及中文释义；源项目 `.env` 不进入交付包。

安装中断后，处理提示原因并双击“继续完成安装.cmd”。该入口使用原安装选项和已生成凭据；完成安装时不重复覆盖数据库。错误与详细日志在 `package/.local/logs`，最新说明为 `last-install-error.txt`。

安装器不自动删除已有 Docker 数据。端口占用时停止并报告，恢复数据要求空目标。多电脑网络和设备接口须在现场按实际地址核对。

全部试验间的准备、开始和结束使用 MQTT；高低温湿热二室本地装样及夹具就绪例外继续保留。
