# 工位客户端 v1.6.0 本机验证

日期：2026-11-07。

## 交付范围

桌面 `MES工位客户端_本机测试`：11 个独立实验间文件夹，以及可视化管理、接驳区系统、暂存间系统、外观检测间系统，共 15 个。各文件夹包括自身的 EXE、WebView2 组件、配置、使用说明及校验清单。

- EXE 固定模块；实验间 EXE 同时固定实验间名称、标准编号和启动路径。
- 登录与退出登录不提供工位切换；页面请求使用编译绑定的实验间。
- 每个工位使用独立实例、网页用户数据和下载目录。
- 默认最大化，保留标准 Windows 窗口按钮；关闭前确认，默认取消，确认后仅关闭该界面。
- 支持现有深浅主题；保留现有账号认证与固定终端绑定校验。

原中控安装版仍为 v1.5.1，控制中心仍为 v2.8.2。当前前端生产构建为 v1.6.0，与旧版中控兼容。

## 桌面交付目录验证

15 套交付程序均连接本机 `http://127.0.0.1:5173` 成功启动到各自的专用登录页，模块及实验间身份匹配，页面脚本错误为 0。最初发现前端 5173 未监听，已单独补启现有静态前端并更新服务状态文件中的前端 PID；未重启后端或模拟器。随后后端、前端、LIMS 和上位机四项 HTTP 健康检查均返回 200。

交付目录原有 137 个清单文件已校验，随包加入本记录后重新登记总清单。本轮本机启动检查仅加载登录页，不代替现场账号登录和完整实验流程验收。

## 验证边界

测试使用临时端口和临时网页；现有实验间和可视化页面通过组件运行测试覆盖。未在真实系统自动登录、创建任务、操作实验或迁移数据；未进行现场电脑注册及开机启动配置。

MQTT、实验业务状态流转及高低温湿热二室本地样品安装／夹具例外未修改。没有运行与本轮客户端展示和入口变更无关的全量后端测试。
