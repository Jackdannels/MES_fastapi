# MES 控制中心 v2.10.0

日期：2026-11-11。当前迭代先用于开发环境；本轮不重新构建 Docker 交付包。

## 开发环境维护修复（2026-11-12）

本轮只更新开发环境。Docker 交付包及安装进度/耗时优化留待迁移阶段。

控制中心图标采用用户指定的蓝色轨道与四向星芒图案，EXE 外壳、标题栏/任务栏及侧栏品牌图标保持一致。构建使用固定 ICO 资源，包含16至256像素的多尺寸帧；离线补全库同步保存对应控制中心程序。

- 客户端确认关闭后立即隐藏窗口，再释放 WebView2；取消关闭保留当前页面和浏览器实例。停止心跳与重连后执行有界退出，不等待缺失的浏览器退出事件六秒。
- 控制中心关闭/重启系统前并行关闭本目录的受管客户端，随后操作服务。不存在或未运行的客户端不启动关闭辅助程序。服务结果与界面结果分别记录，界面异常不误报后台仍运行。关闭阶段耗时写入 `%LOCALAPPDATA%/MesFastApiLauncher/logs/control-center-operations.log`；客户端日志包含 `shutdown.*` 记录。
- 开发目录统一为控制中心 EXE、`中控管理`、`工位终端`、`测试终端` 和说明/校验文件。内部组件资源、清单、备份与日志位于隐藏的 `.mes` 目录。不额外生成终端管理或工作台设置 EXE。兼容旧 `central-client` 路径。
- 新增“系统完整性”：启动时轻量检测；手动完整校验文件哈希。区分完整、未安装、缺失/损坏、配置异常。勾选指定组件后从同版本离线压缩包补全。
- 补全校验资源和文件，拒绝越界、链接目录、损坏包及运行中的组件。替换前备份，失败回退；原配置、绑定文件、服务凭据和业务数据不被覆盖。配置异常提示人工处理。
- 缓存丢失时可选择同版本组件库的 `catalog.json`。控制中心本身不在运行中覆盖；关闭后可运行 `.mes/恢复控制中心.cmd` 恢复 EXE。

## 预置工位与综合测试终端

原开发目录新增 `工位终端`，包含 11 个试验间与可视化、接驳区、暂存间、外观检测间，共 15 个独立工位文件夹。每个文件夹都有对应工位 EXE 和独立的 `MES终端接入.exe`。

根目录的通用 `终端接入` 文件夹已删除；后续构建和更新开发目录也不再生成该文件夹。工作机使用各工位文件夹中的专用接入入口。

接入窗口默认并固定对应工位，服务器地址允许修改。首次审批且本地文件校验成功时激活当前文件夹；已重置绑定、管理员改派工位或预置包无法使用时，沿用审批后生成新桌面工位目录的流程。凭据按当前 Windows 用户加密保存。

新增 `测试终端/MES综合测试终端.exe`。使用开发测试账号登录后，通过业务页面右上角“退出登录 → 切换其他界面”切换中控、全部试验间及其他工位，共 16 个业务页面；不包含上位机与 LIMS 模拟器。测试客户端不额外增加左侧切换栏或顶部横条。测试终端有独立登录目录，页面切换经过原服务器账号会话校验，普通工位仍固定工位。

测试终端的业务操作使用当前连接的 MES 环境。

### 显示清晰度修复（2026-11-12）

旧客户端缺少高 DPI 启用配置，实测窗口为 DPI 不感知模式。本次客户端统一使用 .NET Framework 4.8 的 PerMonitorV2，随所在显示器 DPI 渲染，避免系统对整个窗口进行位图拉伸；WebView2 页面缩放为 100%，保留自动显示器像素密度跟踪。测试端继续复用页面右上角切换入口。

本机 100% 显示器与原生渲染器注入 125%/150% 像素密度检查通过；这不代表已在其他 PC 上复现并消除所有模糊来源。其他电脑需完整替换客户端文件夹中的程序和 EXE.config，再复核效果；若仍模糊，结合客户端 `display` 日志检查实际 DPI、页面缩放及系统兼容性设置。

后续构建开发目录会自动包含这些文件。更新已有目录可运行 `scripts/update_development_terminals.ps1 -OutputDirectory 已有开发目录 -Offline`，保留已有客户端配置并更新程序、说明及清单。

## 终端申请与审批

将对应的完整工位文件夹复制到工位电脑，运行其中的“MES终端接入.exe”。窗口默认固定为该工位，填写 MES 主机地址后点击“提交绑定申请”。申请端不需要管理员密码。

控制中心使用管理员账号连接后，在 **终端管理 → 绑定申请与记录** 中核对电脑名、IP 和申请编号，可调整分配工位，批准或拒绝。申请 24 小时内有效。

批准后，工作机领取自己的凭据，下载并校验对应工位包，在当前 Windows 用户桌面的 `5826工位客户端/工位名称` 下生成完整文件夹。点击“打开新工位”进入；后续直接双击该 EXE。已有目录不覆盖，重新绑定会创建带时间标识的新目录。

工作机 IP 可自动获取，身份由设备标识与凭据确认。MES 主机访问地址需要稳定。

## 终端重置与清理

- “重置绑定”：使选中终端的旧凭据、票据和登录会话失效，工作机重新申请并经审批后生成新工位。
- “删除终端”：移除指定终端的授权和运行记录。
- “清理历史终端”：先预览未经过新申请流程、当前离线的记录，确认后清理；服务器会再次核对状态，保护已上线和新绑定终端。
- 这些操作不删除任务、样品、试验历史或报告。

离线终端不能接收即时文件操作；重新上线后按新流程申请。一个 Windows 用户可以安装多个工位，每个工位保持独立绑定。

## 菜单和在线状态

移除重复的“连接设置”菜单，连接与管理员认证保留在终端管理页。独立工位客户端 v1.8.0 增加心跳和刷新命令支持；重置后显示重新申请入口，远程关机权限不自动开启。

## 开发环境

后端使用现有 MySQL 事务，将申请状态与固定终端凭据一起提交；不在运行时创建表。申请凭据、绑定凭据在工作机上使用当前 Windows 用户的 DPAPI 加密保存。

通过 `scripts/build_workstation_clients.ps1` 编译工位客户端后，用 `scripts/build_terminal_packages.py --source 工位目录` 生成服务端的可分发工位包。默认输出 `app/assets/terminal-clients`；该目录不纳入 Git。
