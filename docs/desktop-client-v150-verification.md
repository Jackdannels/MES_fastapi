# 防误关与重新打开中控

日期：2026-11-07。中控客户端 v1.5.0，MES 控制中心 v2.8.1。

## 本次范围

只实现用户选定的方案 1 和方案 4：

- 中控窗口关闭或 Alt+F4 时二次确认，默认取消。取消保留页面和 WebView2 进程；确认后退出界面，控制中心继续保留。
- 控制中心首页访问地址区域新增“打开中控管理”：已关闭则打开，已运行则唤起同一窗口。不会执行后台服务启动或重启。
- 控制中心已经确认的停止／重启和客户端更新命令沿用明确关闭命令，不重复弹出界面退出确认。
- 版本按用户要求统一为控制中心 v2.8.1；客户端单独迭代为 v1.5.0。

## 本机验证

- 53 项客户端、控制中心、更新及组合窗口相关测试通过。
- 关闭取消保留原进程，关闭确认释放客户端；程序化关闭与更新流程不阻塞。
- 新按钮存在，服务运行时仍可使用；可唤起已有中控并在关闭后重新打开。
- 最终 v2.8.1 程序元数据、标题、关于页面、更新包与配置保留的 25 项桌面工具回归通过。
- 前端版本显示的 3 项定向测试与生产构建通过。

测试使用临时端口、隔离配置和模拟服务脚本。没有执行真实后台服务停止、重启或数据库迁移。已解压目录更新保留地址配置，旧版位于 `.client-updates`。
