## 验收中修复

- 查询命令不再创建单实例锁，避免查询先于主程序启动时抢占身份。
- 并发关闭和初始化中关闭均等待主程序实际退出；关闭时停用恢复计时器。
- 即使 JSON 配置在运行中损坏，关闭和状态命令仍可定位原实例。
- Windows PowerShell 构建脚本使用 UTF-8 BOM，保证中文文件名正确。
- 新客户端出现配置/启动失败时，控制中心返回明确提示。

## 部署前待验收

- 部署本次 `frontend/dist` 后，在真实服务器完成中控管理员登录、退出、主题和排程拖拽。
- 检查真实报告、二维码和历史任务文件下载；实际打印机适配由现场验证。
- 新电脑的运行库安装、开机恢复、目标分辨率和局域网服务器连接。
- 控制中心服务停止/重启使用现有服务脚本；本次没有在正在工作的机器上执行真实停服。
- Docker、原生部署使用匹配的桌面工具配置。独立客户端本身不绑定部署方式。

## 交付边界

本批只启用中控管理；其他工位继续使用原有入口。客户端固定角色用于界面约束，实际授权仍由服务器管理员会话承担。远端终端关闭和自动启动策略将在其他工位迁移阶段接入现有终端链路。
