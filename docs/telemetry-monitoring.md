# 7号屏分层通信状态

遥测周期为 1 秒。`TELEMETRY_DELAYED_AFTER_SECONDS=5`、`TELEMETRY_OFFLINE_AFTER_SECONDS=15` 可配置（必须满足 0 < 延迟 < 失联）。本功能仅监视遥测，不据此结束实验或改变样品、托盘、夹具流程。

## 数据约定

Topic 仍为 `mes/v1/labs/{lab_code}/telemetry/snapshot`。上位机对 `test_device`、`carrier_device` 分别发送：

```json
{
  "configured": true,
  "online": true,
  "observed_at": "2026-09-16T14:32:08+08:00",
  "temperature_c": 35.4,
  "voltage_v": 220.1
}
```

`observed_at` 表示最后一次成功采集，重发旧采样不得修改该时间。兼容未提供分组时间的消息时使用整包 `observed_at`。上位机心跳正常但设备采样时间停止推进，也会产生设备级延迟/失联。设备失联时发送 `online=false`、空数值，不伪造 0 V。缺失设备状态不默认在线。未配置搬运设备使用 `configured=false`，不计入故障。

MES 保留各组最后有效值、最后有效采集时间，且只在通信正常并有新采样时更新。失联后首次有效采样显示恢复确认中，连续第二次有效采样恢复正常；重复序号和重复采样时间不能满足恢复条件。

## 显示与告警

- 单台设备失联：仅对应两项指标变为“—”，显示最后值；其他组正常更新。
- 上位机失联：整间显示“下游状态未知”，全部数值变为“—”。不推断设备已停止。
- 数据延迟：保留旧值并明确标记。过期/失联数据不触发新的温度或电压告警；断线前告警保留为待确认，待有效采样恢复后再评估。
- MES API 请求失败/超时，或 MQTT subscriber 未连接：全屏监控链路中断，状态未知，不误报所有上位机同时故障。
- 告警槽、最后值槽、页脚和边框宽度永久固定。告警不插入新行、不改变卡片位置。

## 模拟器随机事件

每第 10 个已连接采集轮次，从启用且无活动故障的试验间随机选择一间，生成下列一种事件：

| 事件 | 持续轮数（每轮1秒） | 传输行为 |
| --- | --- | --- |
| 高温 64–78°C | 3 | 正常发送异常数值 |
| 低电压 68–95V | 3 | 正常发送异常数值 |
| 试验设备失联 | 6 | 设备 offline，其他数据继续发送 |
| 搬运设备失联 | 6 | 搬运设备 offline，其他数据继续发送 |
| 数据延迟 | 7 | 暂停该试验间遥测 |
| 上位机失联 | 20 | 暂停该试验间遥测，超过15秒由 MES 判断失联 |

长故障持续到期，不被下一次随机事件覆盖。上位机失联模拟限定在遥测，不断开承载所有试验间业务命令的共享 MQTT 连接。真实共享连接中断由 MES 的监控链路状态检测。高低温湿热二室无搬运设备，不生成搬运设备失联；其安装/夹具就绪本地例外维持原定义。
