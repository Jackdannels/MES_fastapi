# MES 控制中心 v2.9.0

日期：2026-11-10。

本版本新增系统配置管理，因此由 v2.8.2 迭代为 v2.9.0。程序程序集与文件版本为 `2.9.0.0`，界面、快捷方式、桌面工具清单和更新包清单统一为 `2.9.0`。

## 系统配置

左侧新增 **系统配置**，集中编辑数据库连接、RabbitMQ / AMQP、MQTT、HTTP / LIMS、文件备份及登录等重要参数。支持分组、搜索、隐藏密码、参数校验、原文件备份、外部修改冲突检测，以及保存配置或保存并重启。

本次按用户要求直接在 v2.9.0 内精简页面：默认只显示实际文件中已有的重要项，每项提供中文名称和用途说明；勾选“显示未配置项”可补充重要连接参数。界面不再预填代码默认值，未配置与显式空值分别显示；其他内部参数保留在原文件中。

## 重复启动提示

开发测试版、Docker 版和原生版共用窗口实例检查：同一 Windows 用户在同一安装目录重复启动控制中心，会在已有窗口提示“控制中心已打开。”并恢复最小化的窗口。重复点击不创建第二个控制中心，也不执行服务启动、停止或重启。不同安装目录各自独立，关闭程序后可重新打开。

更新后的 EXE 重新启动后生效。命令行打开中控、文件自检和预览生成继续独立运行。

本机开发写入项目 `.env`；Docker 写入所选部署环境文件；原生版写入 `nativeConfig.environment`。未修改的配置沿用原值，运行中的进程在重启后读取新值。详细行为与边界见 [系统配置说明](control-center-configuration.md)；更新包内同一文档名为“系统配置说明.md”。

原生控制中心启动时请求管理员权限，以访问受 ACL 保护的配置，不扩大配置目录的访问权限。工作台设置和终端管理程序的权限保持原来的方式。

## 配套部署与更新

更新包包含 Docker / 原生版控制中心、Docker Compose 参数入口及原生服务入口；更新脚本校验文件、保存回退文件、更新部署清单，保留原来的业务配置与数据。

1. 关闭要升级的控制中心。自 v2.8.2 起，正常退出会确认并关闭系统，请安排在允许停机时更新。
2. 解压更新包，在 PowerShell 中运行下列命令；原生版使用管理员 PowerShell。

   ```powershell
   .\Update-ControlCenter.ps1 -DesktopToolsDirectory '实际桌面工具目录'
   ```

3. 从新快捷方式打开 v2.9.0，在“系统配置”中检查实际文件路径后编辑。
4. 保存后重启系统使新参数生效。连接账号必须已存在于目标数据库或消息服务；编辑器不执行服务端改密、账号创建或数据迁移。

Docker 监听端口、客户端公开地址、镜像和部署身份仍由部署工具同步管理，不列入精简页面。已有但未接入当前 Compose 的重要变量为只读，避免保存后没有效果。

## 保留的行为

中控、LIMS 和上位机三合一入口、“打开中控管理”、服务操作进度，以及关闭控制中心时确认并关闭系统的行为继续保留。

所有实验室的实验准备、开始、结束仍使用 MQTT；高低温湿热二室的本地装样与夹具就绪例外保持原样。
