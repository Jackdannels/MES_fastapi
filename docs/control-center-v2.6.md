# MES 控制中心 v2.6

后续版本及当前升级入口见 [MES 控制中心 v2.7](control-center-v2.7.md)。

当前开发环境入口：桌面 `MES控制中心_v2.6.exe`。直接管理本项目的 API 8000、Web 5173、LIMS 8900 和上位机 8899，不需要 Docker 或原生离线安装。

## 修复重启完成后按钮一直灰色

旧控制中心会等待错误输出管道结束。服务或浏览器子进程继承该管道时，控制脚本即使已退出并写出完成结果，控制中心仍可能一直等待，导致按钮保持忙碌状态。

v2.6 继续并发读取错误信息，避免长错误输出堵塞；控制脚本退出后只短暂等待输出收尾，不再以后台子进程关闭管道作为完成条件。操作成功和失败均在 finally 中恢复按钮与光标，再异步刷新服务和终端状态。

服务运行时，“启动系统”保持禁用以避免重复启动；“关闭系统”和“重启系统”应恢复可选。服务停止后，“启动系统”恢复可选。

## 中心进度弹窗

启动、关闭、重启均显示控制中心窗口中央的进度弹窗，分别提示当前操作。

- 进度为估算值；实际操作仍未结束时最多显示 95%。
- 收到真实成功结果后显示 100%，停留约 0.65 秒后自动消失，不再弹出需要点击确认的成功提示。
- 操作失败时关闭进度弹窗，显示错误详情并恢复可用按钮，不会显示成功完成。
- 操作期间暂停自动服务轮询，避免刷新消息覆盖操作状态；完成后恢复轮询。

使用桌面新版本测试，旧 v2.5 EXE 不含这次界面与等待逻辑修复。Docker 部署的已有路径配置和启动设置参见 [v2.5 部署升级说明](control-center-v2.5-upgrade.md)；通过源码构建的 Docker/原生桌面工具同样包含 v2.6 修复，旧安装器副本不会自动更新。

## 验证

已覆盖后台进程继承错误管道、长错误输出、缺少结果、结构化错误、连续执行启动/关闭/重启、100% 自动关闭、按钮恢复和弹窗居中。

当前开发环境实际重启通过：约 16.5 秒返回控制中心，观察到 100% 后弹窗自动隐藏，“关闭”和“重启”恢复可选，后台服务继续运行。现场重启耗时会随服务和电脑状态变化。
